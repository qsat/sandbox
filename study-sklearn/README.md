## 既知のブロッカー

- 環境のネットワークポリシーが `scikit-learn.org` を 403 で拒否する。
- 解除手順: 環境設定 (Network access) で `scikit-learn.org` を許可ドメインに追加。
- 解除されるまで、`domain-model.md` は「記憶ベースの仮説」として扱う。
