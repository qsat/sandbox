## 1. OMP の 2 つの形

**本文の式**:

```math
\underset{w}{\arg\min} \ \| y - X w \|_2^2 \quad \text{subject to} \quad \| w \|_0 \le n_{\text{nonzero\_coefs}}
```

```math
\underset{w}{\arg\min} \ \| w \|_0 \quad \text{subject to} \quad \| y - X w \|_2^2 \le \text{tol}
```

### 記号をもう一度

- $`\lVert w \rVert_0`$: **0 でない係数の個数**。$`w = (0, 1.5, 0, -0.2)`$ なら 2 です。
- $`\arg\min`$: 「いちばん小さくする**そのもの**（ここでは $`w`$）」（[数学の準備「min と argmin」](../../00_math_primer.md#min)）。
- subject to: 「〜という条件のもとで」。

### なぜ「全部試す」のは無理なのか

「ちょうど k 個の特徴を使う最良の組み合わせ」を確実に見つけるには、組み合わせを全部試す必要があります。

| 候補の特徴の数 | 選ぶ数 | 組み合わせの数 |
|---|---|---|
| 10 | 3 | 120 |
| 100 | 3 | 161,700 |
| 100 | 10 | 約 17 兆 |

特徴が増えると、すぐに計算できない数になります。そこで OMP は、**1 個ずつ欲張りに**選びます。

### OMP の手順を言葉で追う（糖尿病データの例）

1. 最初は何も選ばない。残差 = 目的変数そのもの。
2. 残差といちばん相関の強い特徴を 1 つ選ぶ（本文の実験では `bmi`）。
3. **選んだ特徴だけで最小二乗法をやり直し**、残差を計算し直す（これが「直交射影」。マッチング追跡 MP との違い）。
4. 新しい残差といちばん相関の強い特徴を、次に選ぶ（`s5`）。
5. k 個選ぶまで（または残差が `tol` 以下になるまで）繰り返す。

手順 3 で全部の係数を決め直すので、「前に選んだ特徴の効き目の一部を、新しい特徴がもう一度説明してしまう」ことがありません。そのため、選んだ特徴と残差は、いつも**無相関（直交）**になります。

### つまずきやすい点

欲張りな方法なので、最初に選んだ特徴が「本当の組み合わせ」に入っていないと、後から取り消せません。似た特徴が多いデータでは、選ばれる特徴が不安定になりがちです。

## 2. ベイズ回帰の確率モデル

**本文の式**:

```math
p(y \mid X, w, \alpha) = \mathcal{N}(y \mid X w, \alpha^{-1}), \qquad p(w \mid \lambda) = \mathcal{N}(w \mid 0, \lambda^{-1} \mathbf{I}_p)
```

### 「精度」を数字で

正規分布の幅は、ふつう分散（ばらつき）で表しますが、ベイズ回帰では**精度 = 1 ÷ 分散**を使います。

| 精度 | 分散 | 標準偏差 | 意味 |
|---|---|---|---|
| 4 | 0.25 | 0.5 | ばらつきが小さい（自信がある） |
| 1 | 1 | 1 | |
| 0.25 | 4 | 2 | ばらつきが大きい |

- $`\alpha`$（`alpha_`）: **ノイズ**の精度。観測値が予測のまわりにどれだけ集まっているか。
- $`\lambda`$（`lambda_`）: **係数**の精度。「係数は 0 の近くのはず」という思い込みの強さ。

### なぜ Ridge と同じ答えになるのか（MAP 推定）

ベイズの定理から、「データを見た後の係数のもっともらしさ」（事後確率）は、

```math
\text{事後確率} \propto \underbrace{\text{データの出やすさ（尤度）}}_{\text{ノイズのモデル}} \times \underbrace{\text{係数の出やすさ（事前確率）}}_{\text{係数のモデル}}
```

です。正規分布の確率は $`\exp(-\text{2 乗の量})`$ の形なので、$`-\log`$ をとると掛け算が足し算になり（[数学の準備「log」](../../00_math_primer.md#explog)）、

```math
-\log(\text{事後確率}) = \frac{\alpha}{2} \sum_i (y_i - x_i^T w)^2 + \frac{\lambda}{2} \sum_j w_j^2 + \text{定数}
```

になります。これを小さくする $`w`$ が、事後確率を最大にする $`w`$（MAP 推定）です。全体を $`\frac{2}{\alpha}`$ 倍しても最小の位置は変わらないので、

```math
\sum_i (y_i - x_i^T w)^2 + \frac{\lambda}{\alpha} \sum_j w_j^2
```

となり、**Ridge の `alpha` = $`\lambda / \alpha`$** の式そのものです。本文の実験で `Ridge(alpha=lambda_/alpha_)` と係数が完全に一致したのは、このためです。

数値の例: ノイズの精度 $`\alpha = 4`$、係数の精度 $`\lambda = 2`$ なら、Ridge の正則化の強さは $`2 / 4 = 0.5`$ です。

### 正則化の強さはどう決まるのか（周辺尤度）

Bayesian Ridge は、$`\alpha`$ と $`\lambda`$ を「**この設定で、手元のデータ全体がどれだけ出やすいか**」（周辺尤度）が最大になるように決めます。

- $`\lambda`$ を大きくしすぎる（係数を 0 に縛りすぎる）と、データの傾きを説明できず、出やすさが下がる。
- $`\lambda`$ を小さくしすぎる（何でもあり）と、「どんな係数もありうる」ことになり、確率が薄く広がって、手元のデータの出やすさがやはり下がる。

ちょうどよい中間が選ばれます。「必要以上に複雑な説明は選ばない」という**オッカムの剃刀**が、確率の計算から自然に出てくるのがポイントです。

### 予測の幅（`return_std=True`）

予測の標準偏差は、おおよそ

```math
\text{予測の分散} = \underbrace{\frac{1}{\alpha}}_{\text{ノイズ}} + \underbrace{(\text{係数のあいまいさによる分})}_{\text{データから離れるほど大きい}}
```

の 2 つの和です。データのある場所では後半が小さく、データの範囲の外では大きくなります（本文の図の帯の広がり）。

### つまずきやすい点

- `BayesianRidge.alpha_` は**ノイズの精度**で、Ridge の `alpha`（正則化の強さ）とは別物です。
- ガイドは「精度 $`\lambda^{-1}`$ のガウス事前分布」と書いていますが、式から読み取れるのは「分散 $`\lambda^{-1}`$、精度 $`\lambda`$」です。

## 3. ARD の事前分布

**本文の式**:

```math
p(w \mid \lambda) = \mathcal{N}(w \mid 0, A^{-1}), \qquad \operatorname{diag}(A) = \lambda = \{\lambda_1, \dots, \lambda_p\}
```

### Bayesian Ridge との違いを数字で

| | 係数 1 の精度 | 係数 2 の精度 | 係数 1 の標準偏差 | 係数 2 の標準偏差 |
|---|---|---|---|---|
| Bayesian Ridge | 2 | 2（全員同じ） | 0.71 | 0.71 |
| ARD | 1 | 1,000,000 | 1 | 0.001 |

ARD では、係数 2 の精度がとても大きくなると、「係数 2 はほぼ確実に 0」と思い込むことになり、**特徴 2 は事実上使われなくなります**。どの係数の精度を大きくするかも、データから（周辺尤度の最大化で）決まります。

### $`A^{-1}`$ の読み方

$`A`$ は対角に $`\lambda_1, \dots, \lambda_p`$ が並び、ほかが 0 の表（対角行列）です。その逆行列 $`A^{-1}`$ は、対角に $`1/\lambda_1, \dots, 1/\lambda_p`$（各係数の分散）が並びます。「係数どうしは無関係で、それぞれ自分の幅を持つ」という意味です。

### つまずきやすい点

ガイドは各係数の標準偏差を $`1/\lambda_i`$ と書いていますが、正確には分散が $`1/\lambda_i`$、標準偏差は $`1/\sqrt{\lambda_i}`$ です（上の表の値）。「$`\lambda_i`$ が大きいほど幅が狭い」という結論は同じです。
