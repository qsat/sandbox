## 1. OMP の 2 つの形

> - **$`\arg\min_w`$**: 「後ろの式を最小にする $`w`$ そのもの」。$`\min`$ が最小値を表すのに対し、$`\arg\min`$ はそのときの $`w`$ を表す。
> - **subject to**: 「〜という条件のもとで」。制約条件を表す。

### 🔢 数式を読む

**個数を指定する形**

```math
\underset{w}{\arg\min} \ \| y - X w \|_2^2 \quad \text{subject to} \quad \| w \|_0 \le n_{\text{nonzero\_coefs}}
```

**日本語で読むと**: 「0 でない係数は `n_nonzero_coefs` 個まで」という条件のもとで、残差の二乗和を最小にする係数を探す。

**誤差を指定する形**

```math
\underset{w}{\arg\min} \ \| w \|_0 \quad \text{subject to} \quad \| y - X w \|_2^2 \le \text{tol}
```

**日本語で読むと**: 「残差の二乗和が `tol` 以下」という条件のもとで、0 でない係数の数をできるだけ少なくする。

💡 L0 の条件をそのまま満たす最適解を探すには、特徴の組み合わせを全部試す必要があり、特徴が多いと現実的ではありません（組み合わせの数が爆発する）。OMP は、それを貪欲法で**近似**します。

## 2. ベイズ回帰の確率モデル

Ridge の L2 正則化は、係数 $`w`$ に精度 $`\lambda^{-1}`$ の**ガウス事前分布**を置いたときの**最大事後確率（MAP）推定**と等価です。$`\lambda`$ を手で決める代わりに、**確率変数として扱ってデータから推定**できます。

完全な確率モデルにするため、出力 $`y`$ は $`Xw`$ のまわりにガウス分布すると仮定します。

```math
p(y \mid X, w, \alpha) = \mathcal{N}(y \mid X w, \alpha^{-1})
```

ここで $`\alpha`$（ノイズの精度）も、データから推定する確率変数として扱います。

> - **最大事後確率（MAP）推定**: 事後分布が最大になる 1 点を答えにする推定方法。
> - **精度（precision）**: 分散の逆数。分散が小さい（ばらつきが小さい）ほど精度は大きい。ベイズ回帰では計算が簡単になるので、分散の代わりに精度を使うことが多い。
> - **$`\mathcal{N}(y \mid m, v)`$**: 「$`y`$ は、平均 $`m`$・分散 $`v`$ の正規分布に従う」という記法。

### 🔢 数式を読む: ノイズのモデル

```math
p(y \mid X, w, \alpha) = \mathcal{N}(y \mid X w, \alpha^{-1})
```

| 記号 | 意味 |
|---|---|
| $`p(y \mid X, w, \alpha)`$ | 特徴 $`X`$・係数 $`w`$・ノイズの精度 $`\alpha`$ が決まったときの、$`y`$ の確率分布 |
| $`X w`$ | 分布の中心（線形モデルの予測値） |
| $`\alpha^{-1}`$ | 分布の分散。精度 $`\alpha`$ の逆数なので、$`\alpha`$ が大きいほどばらつきが小さい |

**日本語で読むと**: 観測値 $`y`$ は、線形モデルの予測値 $`Xw`$ のまわりに、分散 $`1/\alpha`$ の正規分布でばらつく。「予測 + 正規分布のノイズ」というモデルです。

💡 **なぜ「Ridge = ガウス事前分布の MAP 推定」なのか**: 事後確率の対数は「対数尤度 + 対数事前確率」です。正規分布のノイズの対数尤度は「−（残差の二乗和）× 定数」、係数のガウス事前分布の対数は「−（係数の二乗和）× 定数」になります。これを最大にすることは、「残差の二乗和 + 定数 × 係数の二乗和」を最小にすること、つまり Ridge の式そのものです。

> ⚠️ **記号の注意**: ここでの $`\alpha`$ は**ノイズの精度**（分散の逆数）で、Ridge の `alpha`（正則化の強さ）とは**別物**です。紛らわしいので気をつけてください。$`\lambda`$ が「係数の精度」で、こちらが Ridge の正則化の強さに対応します。

係数 $`w`$ の事前分布は、球状のガウス分布です。

```math
p(w \mid \lambda) = \mathcal{N}(w \mid 0, \lambda^{-1} \mathbf{I}_p)
```

$`\alpha`$ と $`\lambda`$ の事前分布には、ガウス分布の精度の共役事前分布であるガンマ分布を選びます。こうして得られるモデルを Bayesian Ridge 回帰と呼び、古典的な Ridge に似ています。

$`w`$、$`\alpha`$、$`\lambda`$ は学習中に同時に推定されます。正則化パラメータ $`\alpha`$ と $`\lambda`$ は、**対数周辺尤度を最大化**して決めます（Tipping 2001 の付録 A のアルゴリズムと、MacKay 1992 の更新式）。最大化の初期値は `alpha_init` と `lambda_init` で指定できます。ガンマ事前分布の 4 つのハイパーパラメータ $`\alpha_1, \alpha_2, \lambda_1, \lambda_2`$ は、ふつう無情報になるように選び、既定値はすべて $`10^{-6}`$ です。

> 📚 **用語**
> - **球状のガウス分布**: どの向きにも同じだけ広がる多変量正規分布。$`\lambda^{-1} \mathbf{I}_p`$ は「対角がすべて $`1/\lambda`$ の行列」で、全係数が同じ分散 $`1/\lambda`$ を持ち、互いに無相関であることを表す。
> - **ガンマ分布**: 正の値だけをとる確率分布。精度（必ず正）の事前分布によく使われる。
> - **共役事前分布**: 事前分布と事後分布が同じ種類の分布になる組み合わせ。計算が式で閉じるので扱いやすい。
> - **周辺尤度（エビデンス）**: 係数 $`w`$ のありうる値すべてについて平均した尤度。「この $`\alpha, \lambda`$ の設定は、データ全体をどれくらいうまく説明できるか」を表す。これを最大にする $`\alpha, \lambda`$ を選ぶのが、Bayesian Ridge の正則化の決め方。
> - **不良設定問題（ill-posed problem）**: 解が存在しない、1 つに決まらない、またはデータの小さな変化で解が大きく変わる問題。1/4 の多重共線性の状況がその例。

### 🔢 数式を読む: 係数の事前分布

```math
p(w \mid \lambda) = \mathcal{N}(w \mid 0, \lambda^{-1} \mathbf{I}_p)
```

**日本語で読むと**: データを見る前は、「各係数は 0 を中心に、分散 $`1/\lambda`$ でばらつく値だろう」と考えておく。$`\lambda`$ が大きい（精度が高い）ほど「係数は 0 に近いはず」という思い込みが強く、Ridge の正則化が強いのと同じ意味になる。

> ⚠️ **記号の注意（ガイドの表現）**: ガイドには「精度 $`\lambda^{-1}`$ のガウス事前分布」とありますが、式 $`\mathcal{N}(w \mid 0, \lambda^{-1} \mathbf{I}_p)`$ から読み取れるのは「**分散** $`\lambda^{-1}`$、**精度** $`\lambda`$」です。scikit-learn の `lambda_` 属性も精度 $`\lambda`$ を表します。

## 3. ARD の事前分布

### 🔢 数式を読む

```math
p(w \mid \lambda) = \mathcal{N}(w \mid 0, A^{-1}), \qquad \operatorname{diag}(A) = \lambda = \{\lambda_1, \dots, \lambda_p\}
```

| 記号 | 意味 |
|---|---|
| $`A`$ | 対角行列。対角に各係数の精度 $`\lambda_1, \dots, \lambda_p`$ が並ぶ |
| $`A^{-1}`$ | 対角に各係数の分散 $`1/\lambda_1, \dots, 1/\lambda_p`$ が並ぶ |
| $`\lambda_i`$ | 係数 $`w_i`$ の精度。大きいほど「$`w_i`$ は 0 に近いはず」と強く思い込む |

**日本語で読むと**: 係数ごとに別々の「0 への縛りの強さ」を持たせ、その強さもデータから決める。

> ⚠️ **記号の注意（ガイドの表現）**: ガイドは各係数の標準偏差を $`1/\lambda_i`$ と書いていますが、式からは分散が $`1/\lambda_i`$、標準偏差は $`1/\sqrt{\lambda_i}`$ です。「$`\lambda_i`$ が大きいほど係数の幅が狭い」という意味は同じです。

**ガイドの本文の補足**: ガイドは「各係数が自分専用の標準偏差 $`1 / \lambda_i`$ を持つ」と書き、すべての $`\lambda_i`$ の事前分布には、ハイパーパラメータ $`\lambda_1, \lambda_2`$ で決まる同じガンマ分布を使う、としています。
