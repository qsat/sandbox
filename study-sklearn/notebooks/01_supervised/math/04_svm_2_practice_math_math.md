## 1. 4 つのカーネル関数

### 同じ 2 点で、4 つのカーネルを計算する

$`x = (1, 2)`$、$`x' = (2, 0)`$ とします。

- 内積 $`\langle x, x' \rangle = 1 \times 2 + 2 \times 0 = 2`$
- 距離の 2 乗 $`\lVert x - x' \rVert^2 = (1 - 2)^2 + (2 - 0)^2 = 5`$

| `kernel` | 設定 | 計算 | 値 |
|---|---|---|---|
| `"linear"` | — | $`\langle x, x' \rangle`$ | 2 |
| `"poly"` | $`\gamma = 1, r = 1, d = 2`$ | $`(1 \times 2 + 1)^2`$ | 9 |
| `"rbf"` | $`\gamma = 0.5`$ | $`\exp(-0.5 \times 5)`$ | 0.082 |
| `"sigmoid"` | $`\gamma = 0.1, r = 0`$ | $`\tanh(0.1 \times 2)`$ | 0.197 |

値の大きさはカーネルごとに意味が違うので、横に比べることはできません。「同じ 2 点でも、カーネルを変えると“似ている度合い”の測り方が変わる」ことが大事です。

### `gamma='scale'` の計算

$`\gamma = \frac{1}{n_\text{features} \times \operatorname{Var}(X)}`$ です（$`\operatorname{Var}(X)`$ は、全要素をまとめた分散）。特徴が 2 つで、全体の分散が 0.5 なら $`\gamma = \frac{1}{2 \times 0.5} = 1`$。標準化したデータ（分散 1）なら、$`\gamma = \frac{1}{n_\text{features}}`$ です。

特徴が多いほど距離の 2 乗は大きくなりやすい（足し算の項が増える）ので、$`\gamma`$ を小さくして釣り合いをとる、という考え方です。

### カーネルとして使える条件

カーネルは「何かの特徴空間での内積」になっている必要があります（1.3 の $`\phi(x)^T \phi(x')`$）。そのため、どんな点の集まりで作ったカーネル行列も**半正定値**（「似ている度合い」の表として矛盾がない）でなければなりません。線形・多項式・RBF はいつも満たしますが、シグモイドカーネルは $`\gamma`$ と $`r`$ によっては満たさないことがあり、学習が不安定になる原因になります。

## 2. SVC の主問題

**本文の式**:

```math
\begin{aligned}
\min_{w, b, \zeta} \quad & \frac{1}{2} w^T w + C \sum_{i=1}^{n} \zeta_i \\
\text{subject to} \quad & y_i (w^T \phi(x_i) + b) \geq 1 - \zeta_i, \\
& \zeta_i \geq 0, \quad i = 1, \dots, n
\end{aligned}
```

### マージンの幅が $`2 / \lVert w \rVert`$ になる理由（1 次元で）

決定関数 $`f(x) = w x + b`$ で、マージンの境界は $`f(x) = 1`$ と $`f(x) = -1`$ の 2 か所です。$`w = 1, b = 0`$ なら $`x = 1`$ と $`x = -1`$ で、幅は 2。$`w = 2`$ なら $`x = 0.5`$ と $`x = -0.5`$ で、幅は 1。$`f`$ が 1 から −1 まで 2 だけ変わるのに必要な距離は $`2 / w`$ なので、**$`w`$ を小さくするほど道路が広く**なります。

### 分離できるデータでの答え

負のクラス $`x = -2, -1`$、正のクラス $`x = 1, 2`$ なら、答えは $`w = 1`$、$`b = 0`$ です。

| $`x`$ | $`y`$ | $`y f(x)`$ | 状態 |
|---|---|---|---|
| −2 | −1 | 2 | マージンの外（$`\zeta = 0`$） |
| −1 | −1 | 1 | **マージンの境界上**（サポートベクター） |
| 1 | +1 | 1 | **マージンの境界上**（サポートベクター） |
| 2 | +1 | 2 | マージンの外（$`\zeta = 0`$） |

### 邪魔な点を 1 つ足して、$`C`$ の効き方を見る

負のクラスに $`x = 0.5`$ を 1 つ足します（正のクラスの近くに入り込んだ点）。scikit-learn で学習した結果:

| `C` | $`w`$ | $`b`$ | マージン幅 $`2/w`$ | はみ出しの合計 $`\sum \zeta_i`$ | 目的関数 $`\frac{1}{2}w^2 + C\sum\zeta_i`$ |
|---|---|---|---|---|---|
| 1 | 0.667 | −0.333 | **3** | 1.667 | $`0.222 + 1.667 = 1.889`$ |
| 10 | 4 | −3 | **0.5** | 0 | $`8 + 0 = 8`$ |

- `C=1`: はみ出しの罰が軽いので、$`x = 0.5`$ の点を「はみ出し」として許し、広い道路をとります。
- `C=10`: 同じ $`w = 0.667`$ の答えだと目的関数は $`0.222 + 10 \times 1.667 \approx 16.9`$ になって損なので、道路を 0.5 まで狭めて、全部の点をマージンの外に入れます。

`C` は「道路の広さ」と「はみ出しの少なさ」の**交換レート**です。

### $`\zeta_i`$ の値と点の位置

| $`\zeta_i`$ | 点の位置 |
|---|---|
| 0 | マージンの外（正しい側に十分深い） |
| 0〜1 | 正しく分類されているが、マージンの中 |
| 1 | ちょうど境界線（$`f = 0`$）の上 |
| 1 より大きい | 反対側（誤分類） |

## 3. SVC の双対問題と決定関数

**本文の式**:

```math
\begin{aligned}
\min_{\alpha} \quad & \frac{1}{2} \alpha^T Q \alpha - e^T \alpha \\
\text{subject to} \quad & y^T \alpha = 0, \\
& 0 \leq \alpha_i \leq C, \quad i = 1, \dots, n
\end{aligned}
```

```math
\sum_{i \in SV} y_i \alpha_i K(x_i, x) + b
```

### 小さなデータで答えを確かめる

分離できるデータ（$`x = -2, -1, 1, 2`$）では、scikit-learn の答えは

- サポートベクター: $`x = -1`$ と $`x = 1`$
- `dual_coef_`（$`= y_i \alpha_i`$）: $`(-0.5, 0.5)`$、つまり $`\alpha = 0.5`$ ずつ
- `intercept_`: $`b = 0`$

です。制約を確かめると、$`y^T \alpha = (-1)(0.5) + (+1)(0.5) = 0`$ で、両クラスの発言力の合計が等しくなっています。$`x = -2, 2`$ の $`\alpha`$ は 0 なので、予測に関係しません。

### 決定関数を手で計算する

新しい点 $`x = 0.3`$ では、線形カーネル $`K(x_i, x) = x_i x`$ を使って、

```math
(-0.5) \times (-1 \times 0.3) + (0.5) \times (1 \times 0.3) + 0 = 0.15 + 0.15 = 0.3
```

正なので正のクラス。主問題の $`w x + b = 1 \times 0.3 + 0 = 0.3`$ と一致します。

### 主問題と双対問題のつながり（導き方の考え方）

主問題を解いた答えの $`w`$ は、いつも

```math
w = \sum_i y_i \alpha_i \phi(x_i)
```

という形（学習データの混ぜ合わせ）になります。上の例では $`w = (-0.5)(-1) + (0.5)(1) = 1`$ で、主問題の答え $`w = 1`$ と一致します。

- この $`w`$ を目的関数に入れると、$`\frac{1}{2} w^T w = \frac{1}{2} \sum_i \sum_j y_i y_j \alpha_i \alpha_j \phi(x_i)^T \phi(x_j) = \frac{1}{2} \alpha^T Q \alpha`$ になります。これが双対問題の第 1 項の正体で、**$`\phi`$ が内積（カーネル）の形でしか出てこない**のがポイントです。
- 「条件付きの最小化」を、条件ごとに「罰金の単価」$`\alpha_i`$ を用意して解く方法（ラグランジュの未定乗数法）を使うと、$`y^T \alpha = 0`$ は「$`b`$ について傾き 0」、$`\alpha_i \le C`$ は「$`\zeta_i`$ について傾き 0（と $`\zeta_i \ge 0`$）」から出てきます。

### $`\alpha_i`$ の 3 つの状態

| $`\alpha_i`$ | 点の位置 | 主問題で言うと |
|---|---|---|
| 0 | マージンの外 | 条件に余裕がある（罰金の単価 0） |
| $`0 < \alpha_i < C`$ | マージンの境界の上 | $`y_i f(x_i) = 1`$ ちょうど |
| $`C`$（上限） | マージンの中・反対側 | $`\zeta_i > 0`$（はみ出した点） |

`C=1` で邪魔な点を足した例では、`dual_coef_` が $`(-0.056, -1, 1, 0.056)`$ で、$`x = 0.5`$ と $`x = 1`$ の 2 点が上限 $`C = 1`$ に張り付いていました（どちらも $`\zeta > 0`$）。

## 4. LinearSVC とヒンジ損失

**本文の式**:

```math
\min_{w, b} \frac{1}{2} w^T w + C \sum_{i=1}^{n} \max(0, 1 - y_i (w^T \phi(x_i) + b))
```

### なぜ主問題と同じ意味なのか

主問題では、$`\zeta_i \ge 1 - y_i f(x_i)`$ と $`\zeta_i \ge 0`$ の両方を満たす範囲で、$`\zeta_i`$ をできるだけ小さくします。2 つの条件を両方満たす最小の値は、大きいほうの $`\max(0, 1 - y_i f(x_i))`$ です。だから、$`\zeta_i`$ をこの式で置き換えると、条件のない 1 本の式になります。

### ヒンジ損失を数字で

| $`y_i f(x_i)`$（正しい側への深さ） | ヒンジ損失 | 二乗ヒンジ（`LinearSVC` の既定） |
|---|---|---|
| 2 | 0 | 0 |
| 1 | 0 | 0 |
| 0.5 | 0.5 | 0.25 |
| 0 | 1 | 1 |
| −1 | 2 | 4 |

1 の地点で折れ曲がる（蝶番＝ヒンジ）形です。ロジスティック回帰の対数損失（[1.1 3/4 数式編](./01_linear_models_3_classification_glm_math.md#logreg)）と比べると、対数損失は「十分正しい点」にも少しだけ罰を与えますが、ヒンジ損失は**ちょうど 0** にします。だから SVM はサポートベクターだけで決まります。

### なぜ LinearSVC は切片も縮めてしまうのか

liblinear は、切片 $`b`$ を「値がすべて `intercept_scaling` の特徴」の係数 $`w_0`$ として学習します。$`b = w_0 \times`$ `intercept_scaling` なので、

- `intercept_scaling=1`: $`b = 3`$ を表すには $`w_0 = 3`$ が必要で、罰 $`\frac{1}{2} w_0^2 = 4.5`$。
- `intercept_scaling=100`: $`w_0 = 0.03`$ で済み、罰は $`0.00045`$。

`intercept_scaling` を大きくすると、切片への罰が事実上なくなります。

## 5. SVR の主問題と双対問題

**本文の式**（主問題と、`LinearSVR` の形）:

```math
\begin{aligned}
\min_{w, b, \zeta, \zeta^*} \quad & \frac{1}{2} w^T w + C \sum_{i=1}^{n} (\zeta_i + \zeta_i^*) \\
\text{subject to} \quad & y_i - w^T \phi(x_i) - b \leq \varepsilon + \zeta_i, \\
& w^T \phi(x_i) + b - y_i \leq \varepsilon + \zeta_i^*, \\
& \zeta_i, \zeta_i^* \geq 0, \quad i = 1, \dots, n
\end{aligned}
```

```math
\min_{w, b} \frac{1}{2} w^T w + C \sum_{i=1}^{n} \max(0, |y_i - (w^T \phi(x_i) + b)| - \varepsilon)
```

### $`\zeta_i`$ と $`\zeta_i^*`$ を数字で（$`\varepsilon = 0.5`$）

| 実際 $`y`$ | 予測 | 実際 − 予測 | $`\zeta_i`$（上へのはみ出し） | $`\zeta_i^*`$（下へのはみ出し） |
|---|---|---|---|---|
| 3.0 | 2.8 | 0.2 | 0 | 0（チューブの中） |
| 3.0 | 2.2 | 0.8 | **0.3** | 0 |
| 3.0 | 3.9 | −0.9 | 0 | **0.4** |

1 つの点で、$`\zeta_i`$ と $`\zeta_i^*`$ が両方 0 より大きくなることはありません（上と下に同時にはみ出すことはできない）。だから $`\zeta_i + \zeta_i^*`$ は ε-不感損失 $`\max(0, \lvert r \rvert - \varepsilon)`$ と同じです。

### 小さなデータでの答え

$`x = 0, 1, 2, 3, 4`$、$`y = 0, 1.2, 1.9, 3.6, 4.0`$ に、線形カーネルの `SVR(C=1, epsilon=0.5)` を当てはめると:

| $`x`$ | 実際 − 予測 | 位置 | `dual_coef_`（$`\alpha_i - \alpha_i^*`$） |
|---|---|---|---|
| 0 | −0.5 | チューブの下の縁 | −0.289 |
| 1 | −0.167 | チューブの中 | 0（SV ではない） |
| 2 | −0.333 | チューブの中 | 0 |
| 3 | 0.5 | チューブの上の縁 | 0.289 |
| 4 | 0.033 | チューブの中 | 0 |

- サポートベクターは、チューブの縁（または外）にある 2 点だけです。
- 制約 $`e^T(\alpha - \alpha^*) = -0.289 + 0.289 = 0`$ も満たしています。
- `epsilon=0.1` にするとチューブが細くなり、別の 2 点（$`x = 2, 3`$）が上限 $`C = 1`$ の係数を持つサポートベクターになりました。

### 双対問題の各項の意味

| 項 | 意味 |
|---|---|
| $`\frac{1}{2}(\alpha - \alpha^*)^T Q (\alpha - \alpha^*)`$ | 主問題の $`\frac{1}{2} w^T w`$（平らさ）。$`w = \sum_i (\alpha_i - \alpha_i^*) \phi(x_i)`$ を入れたもの |
| $`\varepsilon e^T(\alpha + \alpha^*)`$ | 係数を使うことへのコスト。$`\varepsilon`$ が大きいほど、係数を 0 にしたい（スパースになる） |
| $`-y^T(\alpha - \alpha^*)`$ | 実際の値に合わせる力 |

## 6. 数式と属性の対応

### 1 本の式で全部を確かめる

分類の小さなデータ（$`x = -2, -1, 1, 2`$）で学習した `SVC(kernel="linear")` の属性と、式の記号の対応です。

| 属性 | 値 | 式の記号 |
|---|---|---|
| `support_vectors_` | $`[[-1], [1]]`$ | $`x_i`$（$`i \in SV`$） |
| `dual_coef_` | $`[[-0.5, 0.5]]`$ | $`y_i \alpha_i`$ |
| `intercept_` | $`[0]`$ | $`b`$ |
| `coef_`（線形のときだけ） | $`[[1]]`$ | $`w = \sum_i y_i \alpha_i x_i`$ |

予測は、`dual_coef_` と「サポートベクターと新しい点のカーネル」の内積に `intercept_` を足すだけです。

```python
K = support_vectors_ @ x.T          # 線形カーネル
f = dual_coef_ @ K + intercept_     # decision_function と一致
```

### SVC と SVR の `dual_coef_` の違い

| | 入っている値 | 符号の意味 | 絶対値の上限 |
|---|---|---|---|
| SVC | $`y_i \alpha_i`$ | どちらのクラスの点か | $`C`$ |
| SVR | $`\alpha_i - \alpha_i^*`$ | チューブの上（+）か下（−）か | $`C`$ |

どちらも「上限 $`C`$ に張り付いた係数」は、マージン（チューブ）からはみ出した点です。`np.abs(dual_coef_) == C` の割合を見ると、データのノイズの多さや、`C` が小さすぎないかの目安になります。
