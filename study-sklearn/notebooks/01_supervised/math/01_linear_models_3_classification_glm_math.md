## 1. シグモイド関数

**本文の式**:

```math
\text{確率} = \frac{1}{1 + e^{-z}}
```

### 小さな数で計算してみる

$`e \approx 2.718`$ です（[数学の準備「exp」](../../00_math_primer.md#explog)）。

| 点数 $`z`$ | $`e^{-z}`$ | 確率 $`\frac{1}{1 + e^{-z}}`$ |
|---|---|---|
| −2 | 7.39 | 0.119 |
| −1 | 2.72 | 0.269 |
| 0 | 1 | **0.5** |
| 1 | 0.37 | 0.731 |
| 2 | 0.14 | 0.881 |

- 点数が 0 のとき、ちょうど 0.5。
- 点数がプラスに大きいと $`e^{-z}`$ が 0 に近づき、確率は 1 に近づく。マイナスに大きいと $`e^{-z}`$ が巨大になり、確率は 0 に近づく。
- 表の上下を見比べると、$`\text{確率}(-z) = 1 - \text{確率}(z)`$（0.119 + 0.881 = 1）。S 字は点 (0, 0.5) について対称です。

### 逆向き: 確率から点数へ（ロジット）

確率 $`p`$ から点数 $`z`$ に戻す変換が**ロジット**で、

```math
z = \log \frac{p}{1 - p}
```

です。$`\frac{p}{1-p}`$ は**オッズ**です。確率 0.8 ならオッズは $`0.8 / 0.2 = 4`$、ロジットは $`\log 4 \approx 1.386`$ です。ロジスティック回帰は「**ロジット（対数オッズ）が、特徴の線形結合で表せる**」と考えるモデルです。

### 係数とオッズ比

点数 $`z = w_0 + w_1 \times \text{勉強時間}`$ のとき、勉強時間が 1 増えると $`z`$ は $`w_1`$ 増えます。$`z`$ はオッズの log なので、オッズは $`e^{w_1}`$ **倍**になります。$`w_1 = 0.5`$ なら $`e^{0.5} \approx 1.65`$ 倍です（本文の「オッズ比」の実験）。

## 2. ロジスティック回帰の確率と損失

**本文の式**:

```math
\min_{w} \frac{1}{S} \sum_{i=1}^n s_i \left( -y_i \log(\hat{p}(X_i)) - (1 - y_i) \log(1 - \hat{p}(X_i)) \right) + \frac{r(w)}{S C}
```

### 1 件分の対数損失を計算してみる

正解 $`y_i`$ は 0 か 1 なので、括弧の中は片方しか残りません。

- 正解が 1 のとき: $`-\log \hat{p}`$（クラス 1 に付けた確率の log にマイナス）
- 正解が 0 のとき: $`-\log(1 - \hat{p})`$

| 正解のクラスに付けた確率 | 損失 $`-\log(\text{確率})`$ |
|---|---|
| 0.9 | 0.105 |
| 0.5 | 0.693 |
| 0.01 | **4.605** |

正解に 0.9 を付ければ損失は小さく、「ほぼありえない（0.01）」と言い切って外すと、損失が急に大きくなります。

### なぜ 2 乗誤差ではなく対数損失なのか

- 確率を 0.01 と言って外すのと、0.4 と言って外すのとでは、前者のほうがずっと「悪い」はずです。2 乗誤差ではその差が $`(1 - 0.01)^2 - (1 - 0.4)^2 \approx 0.62`$ しかありませんが、対数損失では $`4.6 - 0.92 \approx 3.7`$ と大きく区別されます。
- 対数損失は係数について**お椀の形（凸）**になるので、どこから始めても同じ答えにたどり着きます。
- 「この係数のとき、手元の正解ラベルがどれくらい出やすいか」（尤度）を最大にすることと、対数損失を最小にすることは同じです（尤度の $`-\log`$ が対数損失）。

### 後半の $`\frac{r(w)}{SC}`$

$`S`$ は重みの合計（重みなしならサンプル数 $`n`$）です。前半は $`S`$ で割って**平均**にしているので、サンプルが増えても前半の大きさは変わりません。後半は $`S \times C`$ で割るので、

- `C` を大きくする → 罰が小さくなる（正則化が弱い）
- サンプルの重みを全部 5 倍にする → $`S`$ が 5 倍 → 罰が 1/5（`C` を 5 倍にしたのと同じ。本文の実験）

### 正則化の表の式

| 正則化 | $`r(w)`$ | $`w = (0.6, -0.8)`$ のとき |
|---|---|---|
| L1 | $`\lVert w \rVert_1 = \lvert w_1 \rvert + \lvert w_2 \rvert`$ | 1.4 |
| L2 | $`\frac{1}{2} w^T w = \frac{1}{2}(w_1^2 + w_2^2)`$ | 0.5 |
| Elastic-Net（$`\rho = 0.5`$） | $`\frac{1 - \rho}{2} w^T w + \rho \lVert w \rVert_1`$ | $`0.25 \times 1 + 0.5 \times 1.4 = 0.95`$ |

## 3. ソフトマックスと多項ロジスティック回帰

**本文の式**:

```math
\hat{p}_k(X_i) = \frac{\exp(X_i W_k + W_{0,k})}{\sum_{l=0}^{K-1} \exp(X_i W_l + W_{0,l})}
```

### 小さな数で計算してみる

3 クラスの点数が $`(2, 1, 0)`$ のとき:

| クラス | 点数 | $`e^{\text{点数}}`$ | 確率（÷ 合計 11.107） |
|---|---|---|---|
| 0 | 2 | 7.389 | 0.665 |
| 1 | 1 | 2.718 | 0.245 |
| 2 | 0 | 1.000 | 0.090 |

点数が 1 違うと、確率の比は $`e \approx 2.7`$ 倍違います（0.665 ÷ 0.245 ≈ 2.7）。

### 全クラスに同じ数を足しても変わらない

点数を $`(12, 11, 10)`$ にしても、$`e^{12} = e^{10} \times e^2`$ のように、分子も分母も同じ $`e^{10}`$ 倍になるので、確率は $`(0.665, 0.245, 0.090)`$ のままです。これが本文の「過剰パラメータ化」（$`K`$ 本の係数を全部ずらしても同じ予測になる）の正体で、1.2 で LDA の `coef_` がソルバによって違ったのも同じ理由です。

### 2 クラスならシグモイドと同じ

点数が $`(z_1, z_0)`$ の 2 クラスなら、クラス 1 の確率は

```math
\frac{e^{z_1}}{e^{z_1} + e^{z_0}} = \frac{1}{1 + e^{-(z_1 - z_0)}}
```

で、「点数の差」をシグモイドに通したものです。ソフトマックスは、シグモイドの多クラス版です。

## 4. GLM の式と単位逸脱度

**本文の式**:

```math
\hat{y}(w, X) = h(Xw), \qquad \min_{w} \frac{1}{2 n_\text{samples}} \sum_i d(y_i, \hat{y}_i) + \frac{\alpha}{2} \|w\|_2^2
```

### 逆リンク関数 $`h = \exp`$ を数字で

| 線形の点数 $`Xw`$ | 予測 $`\exp(Xw)`$ |
|---|---|
| −1 | 0.368 |
| 0 | 1 |
| 2 | 7.389 |

点数がマイナスでも、予測は必ずプラスです。点数が 1 増えると予測は $`e \approx 2.7`$ **倍**になるので、log リンクの係数は「掛け算の効果」として読めます。

### 単位逸脱度を数字で比べる

| 分布 | 単位逸脱度 $`d(y, \hat{y})`$ | 例 1 | 例 2 |
|---|---|---|---|
| 正規 | $`(y - \hat{y})^2`$ | $`y = 10, \hat{y} = 12`$: 4 | $`y = 1, \hat{y} = 3`$: 4 |
| ポアソン | $`2\left(y \log\frac{y}{\hat{y}} - y + \hat{y}\right)`$ | 0.354 | **1.803** |
| ガンマ | $`2\left(\log\frac{\hat{y}}{y} + \frac{y}{\hat{y}} - 1\right)`$ | $`y = 100, \hat{y} = 120`$: 0.0313 | $`y = 10, \hat{y} = 12`$: **0.0313** |

- **正規**: 差が同じ 2 なら、どこでも同じ罰（4）。
- **ポアソン**: 同じ「2 ずれた」でも、値が小さいところ（1 と 3）のほうを約 5 倍重く罰します。件数は、平均が小さいほどばらつきも小さいので、小さいところのずれは「大きな外れ」だからです。
- **ガンマ**: 100 と 120、10 と 12 のように「**同じ比（1.2 倍）**」のずれなら、同じ罰です。金額のように「大きい値ほど誤差も大きい」データに合っています。

### Tweedie の `power` と分散

```math
\operatorname{Var}[Y] \propto \mu^{\text{power}}
```

は「ばらつき（分散）が、平均の何乗に比例するか」です。平均が 10 倍になると、分散は `power=0` なら同じ、`power=1`（ポアソン）なら 10 倍、`power=2`（ガンマ）なら 100 倍（標準偏差が 10 倍）になります。単位逸脱度は、この分散の性質に合わせて「どこのずれを重く見るか」を決めたものです。
