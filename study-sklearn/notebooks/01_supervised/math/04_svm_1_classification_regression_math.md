## 1. 多クラスの `dual_coef_` の並び方

- `dual_coef_` の形は `(n_classes - 1, n_SV)` で、並び方は少し分かりにくいものです。列は、`n_classes * (n_classes - 1) / 2` 個の ovo 分類器のどれかに関わるサポートベクターに対応します。各サポートベクター $`v`$ は、「$`v`$ のクラス」と「ほかのクラス」を比べる `n_classes - 1` 個の分類器のそれぞれで双対係数を持ちます（一部は 0 のこともある）。各列の `n_classes - 1` 個の値は、相手のクラスの順に並びます。

**例**: 3 クラスで、クラス 0 のサポートベクターが 3 個（$`v^0_0, v^1_0, v^2_0`$）、クラス 1 と 2 が 2 個ずつ（$`v^0_1, v^1_1`$ と $`v^0_2, v^1_2`$）とします。サポートベクター $`v^j_i`$ の「クラス $`i`$ と $`k`$ の分類器」での係数を $`\alpha^j_{i,k}`$ と書くと、`dual_coef_` は次のようになります。

| | クラス 0 の SV | | | クラス 1 の SV | | クラス 2 の SV | |
|---|---|---|---|---|---|---|---|
| 1 行目 | $`\alpha^0_{0,1}`$ | $`\alpha^1_{0,1}`$ | $`\alpha^2_{0,1}`$ | $`\alpha^0_{1,0}`$ | $`\alpha^1_{1,0}`$ | $`\alpha^0_{2,0}`$ | $`\alpha^1_{2,0}`$ |
| 2 行目 | $`\alpha^0_{0,2}`$ | $`\alpha^1_{0,2}`$ | $`\alpha^2_{0,2}`$ | $`\alpha^0_{1,2}`$ | $`\alpha^1_{1,2}`$ | $`\alpha^0_{2,1}`$ | $`\alpha^1_{2,1}`$ |

### 🔢 表を読む

- 列 = サポートベクター 1 個。クラス 0 の SV、クラス 1 の SV、クラス 2 の SV の順に並ぶ。
- 行 = 「自分のクラス以外の、何番目の相手か」。クラス 0 の SV なら相手は 1 と 2、クラス 1 の SV なら相手は 0 と 2、クラス 2 の SV なら相手は 0 と 1。
- つまり、同じ「1 行目」でも、列によって相手のクラスが違います。これが「並び方が分かりにくい」理由です。

## 2. Platt スケーリング

### 🔢 数式を読む: Platt スケーリング

```math
P(y = 1 \mid x) = \frac{1}{1 + \exp(A f(x) + B)}
```

**日本語で読むと**: SVM の決定関数の値 $`f(x)`$ を、1.1 の 3/4 で学んだシグモイド関数に通して確率にする。$`A`$（通常は負）と $`B`$ は、「スコアがいくつのとき、実際に何割が正例だったか」をデータから学んで決める。
