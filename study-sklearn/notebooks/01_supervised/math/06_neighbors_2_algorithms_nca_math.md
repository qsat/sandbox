## 1. 総当たりの計算量

### 🔢 数式を読む: $`O[D N^2]`$

| 記号 | 意味 |
|---|---|
| $`N`$ | サンプル数（`n_samples`） |
| $`D`$ | 次元（特徴の数、`n_features`） |
| $`O[\cdot]`$ | 計算量のオーダー（1.4 の 2/2 で説明）。「だいたいこれに比例して増える」 |

**日本語で読むと**: $`N`$ 個の点のすべての組（約 $`N^2`$ 組）について、$`D`$ 個の特徴の差を計算するので、計算量は $`D N^2`$ に比例する。**問い合わせ 1 点あたり**なら、$`N`$ 個との距離を計算するので $`O[DN]`$ になる。

## 2. 三角不等式による下限と上限

### 🔢 数式を読む: 三角不等式で、ノードの中の点をまとめて評価する

ガイドの式 $`|x + y| \le |x| + |y|`$ は、ベクトルの長さ（ノルム）についての三角不等式です。距離の言葉で書き直すと、どんな 3 点 $`q, C, p`$ についても

```math
d(q, p) \le d(q, C) + d(C, p), \qquad d(q, C) \le d(q, p) + d(p, C)
```

です（「寄り道すると、まっすぐ行くより遠くなる」）。ノードの中の点 $`p`$ は $`d(C, p) \le r`$ を満たすので、

```math
d(q, C) - r \;\le\; d(q, p) \;\le\; d(q, C) + r
```

| 記号 | 意味 |
|---|---|
| $`q`$ | 問い合わせ点 |
| $`C`$, $`r`$ | ノード（球）の中心と半径 |
| $`p`$ | ノードの中の任意の点 |
| $`d(q, C)`$ | 問い合わせ点と中心の距離（1 回だけ計算する） |

**日本語で読むと**: 中心までの距離を 1 回測れば、球の中の**どの点も**「中心までの距離 − 半径」より近くはなく、「中心までの距離 + 半径」より遠くはない、と分かる。だから「中心までの距離 − 半径」が今の $`k`$ 番目の候補の距離より大きければ、その球の中の点は 1 つも計算せずに捨てられる。

**ガイドの本文の式**: ベクトルの長さ（ノルム）についての三角不等式

```math
|x+y| \leq |x| + |y|
```

を、距離の言葉で書き直したものが上の式です。

## 3. 縮小重心の式

### 🔢 数式を読む: 縮小重心

```math
d_{cj} = \frac{\bar{x}_{cj} - \bar{x}_j}{m_c \, (s_j + s_0)}, \qquad m_c = \sqrt{\frac{1}{n_c} - \frac{1}{n}}
```

```math
d'_{cj} = \operatorname{sign}(d_{cj}) \, \max\bigl(\lvert d_{cj} \rvert - \Delta,\; 0\bigr), \qquad \bar{x}'_{cj} = \bar{x}_j + m_c (s_j + s_0) \, d'_{cj}
```

| 記号 | 意味 |
|---|---|
| $`\bar{x}_{cj}`$ | クラス $`c`$ の重心の、特徴 $`j`$ の値 |
| $`\bar{x}_j`$ | 全データの平均（全体の重心）の、特徴 $`j`$ の値 |
| $`s_j`$ | 特徴 $`j`$ のクラス内の標準偏差（各クラスの重心からのばらつきをまとめたもの） |
| $`s_0`$ | $`s_j`$ の中央値。$`s_j`$ がたまたま小さい特徴で $`d`$ が大きくなりすぎないようにする安全装置 |
| $`n_c`$, $`n`$ | クラス $`c`$ のサンプル数、全体のサンプル数 |
| $`m_c`$ | 重心の推定の誤差の大きさを表す係数。$`d_{cj}`$ を「標準化されたずれ」にする |
| $`\Delta`$ | `shrink_threshold` |
| $`d'_{cj}`$ | 縮めたずれ。絶対値を $`\Delta`$ だけ小さくし、0 を越えたら 0 にする（**ソフトしきい値**、1.1 の Lasso と同じ形） |
| $`\bar{x}'_{cj}`$ | 縮めた重心（`centroids_`） |

**日本語で読むと**: 各クラスの重心が全体の重心から「どれだけ、ばらつきに比べて有意にずれているか」を測り、そのずれを一律に $`\Delta`$ だけ小さくする。ずれが $`\Delta`$ より小さい特徴は、ずれが 0（＝どのクラスの重心も全体の重心と同じ）になり、その特徴は分類に使われなくなる。

## 4. NCA の目的関数

NCA の目的は、大きさ `(n_components, n_features)` の最適な線形変換の行列 $`L`$ を学習することです。この行列は、すべてのサンプル $`i`$ について、$`i`$ が正しく分類される確率 $`p_i`$ の和を最大化します。

```math
\underset{L}{\arg\max} \sum_{i=0}^{N - 1} p_i
```

ここで $`N`$ は `n_samples`、$`p_i`$ は、学習した埋め込みの空間で、確率的な最近傍の規則によってサンプル $`i`$ が正しく分類される確率です。

```math
p_i = \sum_{j \in C_i} p_{ij}
```

$`C_i`$ はサンプル $`i`$ と同じクラスの点の集まりで、$`p_{ij}`$ は、埋め込みの空間でのユークリッド距離についての **softmax** です。

```math
p_{ij} = \frac{\exp(-\lVert L x_i - L x_j \rVert^2)}{\sum_{k \ne i} \exp(-\lVert L x_i - L x_k \rVert^2)}, \qquad p_{ii} = 0
```

### 🔢 数式を読む

| 記号 | 意味 |
|---|---|
| $`L`$ | 学習する変換の行列（`components_`）。形は `(n_components, n_features)` |
| $`L x_i`$ | サンプル $`i`$ を変換した点（`transform` の結果） |
| $`\lVert L x_i - L x_j \rVert^2`$ | 変換後の空間での、$`i`$ と $`j`$ の距離の 2 乗 |
| $`p_{ij}`$ | 「$`i`$ が、近傍として $`j`$ を 1 つ選ぶ」確率。近いほど大きい。$`i`$ 自身は選ばない（$`p_{ii} = 0`$） |
| $`C_i`$ | $`i`$ と同じクラスの点の集まり |
| $`p_i`$ | $`i`$ が同じクラスの点を選ぶ確率 = $`i`$ が正しく分類される確率 |
| softmax | 値の並びを、指数関数で正にしてから合計で割り、合計 1 の確率にする変換（1.1 の 3/4 の多クラスのロジスティック回帰で登場） |

**日本語で読むと**: 各点が「くじ引き」で近傍を 1 つ選ぶ。近い点ほど当たりやすい。同じクラスの点を引けば正解。全点の正解の確率の合計が最大になるように、空間の伸ばし方 $`L`$ を決める。

## 5. マハラノビス距離としての NCA

NCA は、（2 乗の）**マハラノビス距離**を学習していると見ることもできます。

```math
\lVert L (x_i - x_j) \rVert^2 = (x_i - x_j)^T M (x_i - x_j)
```

ここで $`M = L^T L`$ は、大きさ `(n_features, n_features)` の、**対称な半正定値行列**です。

### 🔢 数式を読む

| 記号 | 意味 |
|---|---|
| $`M = L^T L`$ | 距離の測り方を決める行列。$`M`$ が単位行列なら普通のユークリッド距離 |
| 対称 | $`M^T = M`$（行と列を入れ替えても同じ） |
| 半正定値 | どんなベクトル $`v`$ でも $`v^T M v \ge 0`$（距離の 2 乗が負にならない）。固有値がすべて 0 以上 |

**日本語で読むと**: 「$`L`$ で変換してから普通の距離を測る」のと、「変換せずに、$`M`$ という重み付きの物差しで距離を測る」のは同じこと。$`M`$ は、特徴ごとの伸び縮みと、特徴どうしの組み合わせ（斜めの方向）の伸び縮みを表す。
