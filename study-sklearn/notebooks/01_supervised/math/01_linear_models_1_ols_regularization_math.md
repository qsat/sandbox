## 1. 線形モデルの式

**本文の式**:

```math
\hat{y}(w, x) = w_0 + w_1 x_1 + \dots + w_p x_p
```

### 小さな数で計算してみる

家賃の例（基本料金 $`w_0 = 2.0`$、面積の単価 $`w_1 = 0.2`$、徒歩の単価 $`w_2 = -0.15`$）で、面積 25 m²・徒歩 5 分の物件を計算します。

```math
\hat{y} = 2.0 + 0.2 \times 25 + (-0.15) \times 5 = 2.0 + 5.0 - 0.75 = 6.25 \text{（万円）}
```

「…」（$`\dots`$）は「同じパターンが特徴の数だけ続く」という意味です。特徴が 100 個なら、掛け算と足し算が 100 回続くだけです。

### 内積で書くと

係数を $`w = (w_1, \dots, w_p)`$、特徴を $`x = (x_1, \dots, x_p)`$ のベクトルにまとめると、「掛けて足す」部分は**内積** $`w^T x`$ です（[数学の準備「内積」](../../00_math_primer.md#dot)）。

```math
\hat{y} = w_0 + w^T x
```

さらに、全物件をまとめた表（行列）$`X`$ を使うと、全物件の予測を一度に $`Xw + w_0`$ と書けます（[数学の準備「行列」](../../00_math_primer.md#matrix)）。本文の後の式に出てくる $`Xw`$ は、この「全物件の予測の並び」です。

### つまずきやすい点

- **「線形」は係数について**: $`x_1^2`$ のような特徴を入れても、係数を掛けて足すだけなら線形モデルです（4/4 の多項式回帰）。
- **係数の大きさは単位で変わる**: 面積を m² から cm² にすると、単価は 1/10000 になります。係数を比べて「どの特徴が大事か」を言うときは、特徴を標準化しておく必要があります。

## 2. 最小二乗法の式

**本文の式**:

```math
\min_{w} \| X w - y \|_2^2
```

### 小さな数で計算してみる

データ 3 件 $`(x, y) = (1, 1), (2, 2), (3, 2)`$ に、直線 $`\hat{y} = w_0 + w_1 x`$ を当てはめます。

| 直線 | 予測 | 残差（実際 − 予測） | 残差の 2 乗の合計 |
|---|---|---|---|
| $`\hat{y} = 0.7x`$ | 0.7, 1.4, 2.1 | 0.3, 0.6, −0.1 | $`0.09 + 0.36 + 0.01 = 0.46`$ |
| $`\hat{y} = 0.667 + 0.5x`$ | 1.167, 1.667, 2.167 | −0.167, 0.333, −0.167 | $`0.028 + 0.111 + 0.028 = 0.167`$ |

下の直線のほうが合計が小さく、実はこれが**最小**になる直線（最小二乗法の答え）です。

### 答えの求め方（特徴が 1 つの場合）

特徴が 1 つなら、答えは次の式で直接求まります（$`\bar{x}, \bar{y}`$ は平均）。

```math
w_1 = \frac{\sum_i (x_i - \bar{x})(y_i - \bar{y})}{\sum_i (x_i - \bar{x})^2}, \qquad w_0 = \bar{y} - w_1 \bar{x}
```

上の例では $`\bar{x} = 2`$、$`\bar{y} = 5/3`$ なので、

```math
w_1 = \frac{(-1)(-\tfrac{2}{3}) + 0 + (1)(\tfrac{1}{3})}{1 + 0 + 1} = \frac{1}{2} = 0.5, \qquad w_0 = \frac{5}{3} - 0.5 \times 2 \approx 0.667
```

分子は「$`x`$ と $`y`$ が一緒に動く度合い」（共分散）、分母は「$`x`$ のばらつき」（分散）です。**「$`x`$ が 1 増えたとき、$`y`$ が平均的にどれだけ一緒に増えるか」**が傾きになる、と読めます。

### なぜこの式で最小になるのか

残差の 2 乗の合計を $`w_1`$ の関数として描くと、**お椀の形（下に凸の放物線）**になります。お椀の底では傾きが 0 なので、「傾き（微分）= 0」とおいて解くと上の式が出てきます（[数学の準備「傾き」](../../00_math_primer.md#slope)）。特徴が何個あっても同じ考え方で、まとめて書くと

```math
w = (X^T X)^{-1} X^T y
```

になります（正規方程式。切片は $`X`$ に「全部 1 の列」を足して扱う）。

### つまずきやすい点

- **$`(X^T X)^{-1}`$ が作れないとき**: 本文の多重共線性の話です。同じ情報の列が 2 本あると、$`X^T X`$ が特異（割り算ができない）になり、答えが 1 つに決まりません。scikit-learn は SVD を使い、その中で係数の大きさが最小の答えを返します（本文のガイドの例の `[0.5, 0.5]`）。
- **2 乗するので外れ値に弱い**: 残差 10 の点は、残差 1 の点の 100 倍の重みで効きます（4/4 のロバスト回帰）。

## 3. Ridge 回帰の式

**本文の式**:

```math
\min_{w} \| X w - y \|_2^2 + \alpha \| w \|_2^2
```

### 小さな数で計算してみる（切片なし・特徴 1 つ）

切片なしで $`\hat{y} = w x`$ とすると、最小にする式は $`\sum_i (y_i - w x_i)^2 + \alpha w^2`$ で、答えは

```math
w = \frac{\sum_i x_i y_i}{\sum_i x_i^2 + \alpha}
```

です。上と同じデータ $`(1, 1), (2, 2), (3, 2)`$ では $`\sum x_i y_i = 1 + 4 + 6 = 11`$、$`\sum x_i^2 = 1 + 4 + 9 = 14`$ なので、

| `alpha` | 係数 $`w`$ |
|---|---|
| 0（最小二乗法） | $`11 / 14 \approx 0.786`$ |
| 1 | $`11 / 15 \approx 0.733`$ |
| 14 | $`11 / 28 \approx 0.393`$（ちょうど半分） |

分母に `alpha` が足されるので、`alpha` を大きくするほど係数が**一定の割合で縮みます**。分母が 0 になることもなくなるので、多重共線性で $`X^T X`$ が特異でも、必ず答えが 1 つに決まります。特徴が何個あっても、答えは

```math
w = (X^T X + \alpha I)^{-1} X^T y
```

です（$`I`$ は単位行列。最小二乗法の式の $`X^T X`$ の対角に `alpha` を足したもの）。

### なぜ「そっくりな 2 つの特徴」で半分ずつになるのか

2 つの特徴がまったく同じ値なら、予測に効くのは係数の合計 $`w_1 + w_2`$ だけです。合計を 1 に固定したとき、罰 $`w_1^2 + w_2^2`$ を比べると、

| 分け方 $`(w_1, w_2)`$ | 罰 $`w_1^2 + w_2^2`$ |
|---|---|
| (1, 0) | 1 |
| (0.7, 0.3) | 0.58 |
| (0.5, 0.5) | **0.5（最小）** |

2 乗の罰は「1 人に集中させる」と高くつくので、**均等に分けるほど得**になります。本文の実験で Ridge が (0.5, 0.5) 付近に集まったのは、このためです。

### つまずきやすい点

- **特徴の単位で罰の効き方が変わる**: 単位の大きい特徴は小さな係数で済むので、罰をあまり受けません。Ridge の前には標準化が基本です。
- **切片は罰しない**: scikit-learn の `Ridge` は切片 $`w_0`$ には罰をかけません（データの平均の位置に罰をかける理由がないため）。

## 4. Lasso の式

**本文の式**:

```math
\min_{w} \frac{1}{2 n_\text{samples}} \| X w - y \|_2^2 + \alpha \| w \|_1
```

### 特徴が 1 つのとき、式はどう見えるか

特徴を「2 乗の平均が 1」になるように標準化しておくと（$`\sum_i x_i^2 = n`$）、式の前半は、ほぼ次の形に書き直せます（定数の違いは最小の位置に影響しないので省きます）。

```math
\frac{1}{2}(w - z)^2 + \alpha \lvert w \rvert, \qquad z = \frac{1}{n} \sum_i x_i y_i
```

$`z`$ は「正則化なしのときの係数」です。つまり Lasso は、「**$`z`$ に近い $`w`$ を選びたい**（前半）けれど、**$`w`$ の絶対値には罰金がかかる**（後半）」という綱引きをしています。

### 小さな数で計算してみる

罰の強さ $`\alpha = 0.3`$ とします。

- **$`z = 0.2`$ のとき**: $`w = 0`$ なら $`\frac{1}{2}(0 - 0.2)^2 + 0 = 0.02`$。$`w = 0.1`$ なら $`\frac{1}{2}(0.1 - 0.2)^2 + 0.3 \times 0.1 = 0.005 + 0.03 = 0.035`$。0 のほうが小さい。実際、0 から少しでも動かすと、罰金（1 動かすごとに 0.3）が、当てはまりの改善（最大でも 0.2 程度）を上回るので、**答えはちょうど 0** です。
- **$`z = 0.8`$ のとき**: 答えは $`w = 0.8 - 0.3 = 0.5`$ です。罰金の分だけ 0 の方へ引き戻されます。

これをまとめたのが、本文の「ソフトしきい値」$`S(z, \alpha) = \operatorname{sign}(z) \max(0, |z| - \alpha)`$ です。

### なぜ絶対値の罰は 0 を作るのか（Ridge との違い）

- **2 乗の罰**（Ridge）は、0 の近くではほとんど罰金がかかりません（$`0.1^2 = 0.01`$）。だから少しでも役立つ特徴には、小さな係数が残ります。
- **絶対値の罰**（Lasso）は、0 の近くでも 1 動かすごとに同じ罰金がかかります（$`|0.1| = 0.1`$）。効き目が罰金より小さい特徴は、**最初の 1 歩から赤字**なので、0 のままになります。

### つまずきやすい点

- **Ridge と `alpha` の意味が違う**: Lasso の前半には $`\frac{1}{2 n}`$ が付いていて、「平均」の大きさです。Ridge の式は「合計」なので、同じ `alpha` でも罰の強さはサンプル数の分だけ違います。
- **そっくりな 2 つの特徴では、どちらを選ぶか決まらない**: 合計 $`w_1 + w_2`$ を固定すると、同じ符号の分け方ならどれも罰 $`|w_1| + |w_2|`$ が同じです（2 乗の罰のように「均等が得」になりません）。だから、データのわずかな違いでどちらかに寄ります（本文の Elastic-Net の実験）。

## 5. 座標降下法の 1 ステップ（ソフトしきい値）

**本文の式**:

```math
w_j = \frac{S\left(x_j^T (y - X_{-j} w_{-j}),\ \alpha\right)}{\| x_j \|_2^2}
```

### 1 ステップを順に計算してみる

特徴 $`j`$ 以外の係数を固定して、$`w_j`$ だけを決め直す 1 ステップです。

1. **部分残差** $`r = y - X_{-j} w_{-j}`$: ほかの特徴で予測した残り。
2. **内積** $`x_j^T r`$: 残りと、特徴 $`j`$ がどれだけ同じ向きか。
3. **ソフトしきい値**: それが罰より小さければ 0、大きければ罰の分だけ引く。
4. **割り算** $`/ \lVert x_j \rVert^2`$: 特徴の大きさで割って、係数の単位に直す。

数値の例（サンプル $`n = 10`$、$`\alpha = 0.3`$）:

| $`x_j^T r`$ | しきい値 | $`S(\cdot)`$ | $`\lVert x_j \rVert^2`$ | 新しい $`w_j`$ |
|---|---|---|---|---|
| 12 | $`n\alpha = 3`$ | $`12 - 3 = 9`$ | 10 | 0.9 |
| 2 | 3 | 0（2 は 3 より小さい） | 10 | **0** |
| −5 | 3 | $`-5 + 3 = -2`$ | 10 | −0.2 |

> 💡 **しきい値の $`n`$ について**: scikit-learn の Lasso は当てはまりの悪さを $`\frac{1}{2n}`$ 倍しているので、実際のしきい値は $`n \alpha`$ になります。ガイドの式はこの $`n`$ を省いて書いています（考え方は同じです）。

これを特徴 1, 2, …, p と順に（`selection="cyclic"`）、または順番をランダムに（`selection="random"`）、何周も繰り返します。1 周するごとに式の値は必ず小さくなるので、やがて止まります。

### なぜ 1 つずつでよいのか

山の地図にたとえると、「東西方向にだけ動いて、その方向で一番低い所に行く」「次は南北方向にだけ動いて…」を繰り返す方法です。Lasso の式はお椀の形（凸）なので、この方法でも最後には谷底（最適解）に着きます。1 つの方向だけなら、答えがソフトしきい値で**式 1 本で求まる**のが、この方法が速い理由です。

### 双対ギャップ（止める目安）

「今の答えでの式の値」と「最適な値がこれより下にはない、と保証できる値（下限）」の差です。差が `tol` より小さくなれば、「最適からほとんど離れていない」と分かるので止めます。

## 6. AIC と BIC

**本文の式**:

```math
\text{AIC} = -2 \log \hat{L} + 2d, \qquad \text{BIC} = -2 \log \hat{L} + \log(N) \, d
```

### $`-2 \log \hat{L}`$ は何か

誤差が正規分布だと考えるとき、$`-2 \log \hat{L}`$ は（定数の違いを除いて）「**残差の 2 乗の合計 ÷ ノイズの分散**」になります。つまり「当てはまりの悪さ」です。尤度 $`\hat{L}`$ は大きいほど良いので、マイナスを付けて「小さいほど良い」向きにそろえています。

### 小さな数で比べてみる（サンプル $`N = 100`$、$`\log 100 \approx 4.6`$）

| モデル | 特徴の数 $`d`$ | 当てはまりの悪さ | AIC | BIC |
|---|---|---|---|---|
| A | 2 | 110 | $`110 + 4 = 114`$ | $`110 + 9.2 = 119.2`$ |
| B | 5 | 100 | $`100 + 10 = 110`$ | $`100 + 23.0 = 123.0`$ |

- **AIC は B を選ぶ**: 特徴を 3 つ増やして当てはまりが 10 良くなり、罰の増加（6）より大きいから。
- **BIC は A を選ぶ**: 罰の増加が $`3 \times 4.6 = 13.8`$ で、改善の 10 より大きいから。

同じデータでも、BIC のほうが**少ない特徴**を選びやすいことが、数字で分かります。

### 「8 件以上なら BIC のほうが厳しい」の理由

1 特徴あたりの罰は、AIC が 2、BIC が $`\log N`$ です。$`\log N > 2`$ となるのは $`N > e^2 \approx 7.39`$、つまり $`N \ge 8`$ のときです（[数学の準備「log」](../../00_math_primer.md#explog)）。

### つまずきやすい点

- AIC / BIC は**学習データの上で**計算する指標です。サンプルが少ない、特徴がサンプルより多い、といった条件では当てにならなくなります（本文の 📖 の注意）。
- 「真の特徴を当てたい」なら BIC、「よく予測したい」なら AIC や交差検証、という目安があります（本文の実験）。

## 7. Multi-task Lasso の式

**本文の式**:

```math
\min_{W} \frac{1}{2 n_\text{samples}} \| X W - Y \|_\text{Fro}^2 + \alpha \| W \|_{21}, \qquad \| A \|_{21} = \sum_i \sqrt{\sum_j a_{ij}^2}
```

### 小さな数で計算してみる

特徴 2 つ・タスク 3 つの係数の表 $`W`$（行 = 特徴、列 = タスク）を考えます。

| | タスク 1 | タスク 2 | タスク 3 | 行の長さ $`\sqrt{\sum_j w_{ij}^2}`$ |
|---|---|---|---|---|
| 特徴 1 | 0.5 | 0.4 | 0.6 | $`\sqrt{0.25 + 0.16 + 0.36} \approx 0.877`$ |
| 特徴 2 | 0 | 0.3 | 0 | $`\sqrt{0.09} = 0.3`$ |

混合ノルムは行の長さの合計で、$`\lVert W \rVert_{21} \approx 0.877 + 0.3 = 1.177`$ です。

### なぜ「特徴ごとに丸ごと 0」になるのか

- 外側は**絶対値の合計（L1）**と同じ形なので、Lasso と同じく「行の長さがちょうど 0」になりやすい。行の長さが 0 なら、その特徴の係数は**全タスクで 0** です。
- 内側は**2 乗の合計の平方根（L2）**なので、行の中では Ridge と同じく「均等に広げたほうが得」です。だから、使うと決めた特徴は、全タスクで少しずつ使われます。

上の例の特徴 2 は、タスク 2 だけで 0.3 を使っています。罰が十分強ければ、この行は丸ごと 0 になります（タスクごとの Lasso なら、タスク 2 だけ残ることがある）。

### フロベニウスノルム

$`\lVert XW - Y \rVert_\text{Fro}^2`$ は、全タスク・全サンプルの残差を 2 乗して全部足したものです。タスクごとの残差の 2 乗の合計を、さらにタスクについて足しただけです。

## 8. Elastic-Net の式

**本文の式**:

```math
\min_{w} \frac{1}{2 n_\text{samples}} \| X w - y \|_2^2 + \alpha \rho \| w \|_1 + \frac{\alpha (1 - \rho)}{2} \| w \|_2^2
```

### 小さな数で計算してみる

$`\alpha = 1`$、$`\rho = 0.5`$（`l1_ratio=0.5`）のとき、罰は $`0.5 \lVert w \rVert_1 + 0.25 \lVert w \rVert_2^2`$ です。

そっくりな 2 つの特徴に、合計 1 の係数をどう分けるかで比べます。

| 分け方 $`(w_1, w_2)`$ | L1 の部分 $`0.5 \times (\lvert w_1 \rvert + \lvert w_2 \rvert)`$ | L2 の部分 $`0.25 \times (w_1^2 + w_2^2)`$ | 罰の合計 |
|---|---|---|---|
| (1, 0) | 0.5 | 0.25 | 0.75 |
| (0.7, 0.3) | 0.5 | 0.145 | 0.645 |
| (0.5, 0.5) | 0.5 | 0.125 | **0.625（最小）** |

L1 の部分はどの分け方でも同じなので、**L2 の部分が「均等に分ける」方へ背中を押します**。これが、本文の実験で Elastic-Net が半々に分けた理由（グループ効果）です。一方、L1 の部分があるので、効かない特徴はちょうど 0 になります。

### つまずきやすい点

- **$`\rho`$ の意味**: この式の $`\rho`$ は `l1_ratio`（**L1 の割合**）です。1.5 の SGD の数式編では、ガイドの書き方の都合で $`\rho`$ が「L2 の割合」になっていて、向きが逆です。
- `l1_ratio = 1` なら Lasso、`l1_ratio = 0` なら Ridge（ただし $`\frac{1}{2n}`$ の付き方が違うので、`alpha` の値はそのまま対応しません）。
