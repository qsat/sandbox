## 1. Ridge からカーネルリッジ回帰へ

**本文の式**:

```math
(K + \alpha I) \, a = y, \qquad K_{ij} = k(x_i, x_j) = \phi(x_i)^T \phi(x_j)
```

```math
\hat{y}(x) = \sum_{i=1}^{n} a_i \, k(x_i, x)
```

### 2 点だけで、手で計算してみる

学習データを 2 点 $`x_1 = 0,\ y_1 = 1`$ と $`x_2 = 1,\ y_2 = 2`$ にします。カーネルは RBF $`k(x, x') = \exp(-(x - x')^2)`$（$`\gamma = 1`$）、正則化 $`\alpha = 0.1`$ とします。

**手順 1: カーネル行列を作る**（2 点どうしの「似ている度合い」の表）

| | $`x_1 = 0`$ | $`x_2 = 1`$ |
|---|---|---|
| $`x_1 = 0`$ | $`e^{0} = 1`$ | $`e^{-1} = 0.368`$ |
| $`x_2 = 1`$ | 0.368 | 1 |

自分自身とは必ず 1（いちばん似ている）、距離 1 だけ離れた相手とは 0.368 です。

**手順 2: 連立方程式 $`(K + \alpha I) a = y`$ を解く**

対角に $`\alpha = 0.1`$ を足して、

```math
\begin{cases} 1.1 \, a_1 + 0.368 \, a_2 = 1 \\ 0.368 \, a_1 + 1.1 \, a_2 = 2 \end{cases}
```

これは中学で習う 2 元 1 次の連立方程式です。解くと $`a_1 \approx 0.339`$、$`a_2 \approx 1.705`$ です（`dual_coef_` に入る値）。

**手順 3: 新しい点 $`x = 0.5`$ を予測する**

$`x = 0.5`$ は両方の点から距離 0.5 なので、似ている度合いはどちらも $`e^{-0.25} \approx 0.779`$。

```math
\hat{y}(0.5) = 0.339 \times 0.779 + 1.705 \times 0.779 \approx 1.592
```

「2 つの学習データを、似ている度合いで重み付けして混ぜる」という計算です。

### $`\alpha`$ を変えると、どう変わるか

| $`\alpha`$ | $`a_1`$ | $`a_2`$ | 学習データ上の予測 $`(\hat{y}_1, \hat{y}_2)`$ |
|---|---|---|---|
| 0.001 | 0.306 | 1.886 | (1.000, 1.998) ほぼ正解どおり |
| 0.1 | 0.339 | 1.705 | (0.966, 1.830) |
| 1 | 0.327 | 0.940 | (0.673, 1.060) |
| 10 | 0.085 | 0.179 | (0.151, 0.210) 0 のほうへ縮む |

$`\alpha`$ を大きくするほど、予測は 0 に引き寄せられます（Ridge の「縮小」と同じ）。

### なぜ $`(K + \alpha I) a = y`$ になるのか（導き方）

特徴空間の Ridge の最小化で「傾き 0」の条件を書くと、

```math
w = \frac{1}{\alpha} \sum_{i} \underbrace{(y_i - w^T \phi(x_i))}_{\text{残差}} \, \phi(x_i)
```

になります。つまり、**答えの $`w`$ は、学習データの特徴 $`\phi(x_i)`$ を混ぜ合わせたもの**で、混ぜる割合は $`a_i = \frac{\text{残差}_i}{\alpha}`$ です。

- $`w = \sum_j a_j \phi(x_j)`$ を予測の式に入れると、$`w^T \phi(x) = \sum_j a_j \phi(x_j)^T \phi(x) = \sum_j a_j k(x_j, x)`$。これが本文の予測の式です。
- $`a_i = \frac{y_i - \hat{y}_i}{\alpha}`$ に $`\hat{y}_i = \sum_j K_{ij} a_j`$ を入れて整理すると、$`\alpha a_i = y_i - \sum_j K_{ij} a_j`$、つまり $`(K + \alpha I) a = y`$ です。

上の数値例でも、$`a_1 = \frac{1 - 0.966}{0.1} \approx 0.339`$ になっています。**双対係数は「残差 ÷ $`\alpha`$」**なので、残差がちょうど 0 にならない限り 0 にはなりません（4 章のスパース性の話につながります）。

### 計算量の感覚

| | 主に扱う行列の大きさ | 向いている場面 |
|---|---|---|
| 特徴空間の Ridge | 特徴の数 × 特徴の数 | 特徴が少ない |
| カーネルリッジ回帰 | **サンプル数 × サンプル数** | 特徴が多い（無限でもよい）、サンプルが少〜中 |

サンプルが 1 万件なら $`K`$ は 1 億マスで、連立方程式を解く計算はおよそ $`n^3 = 10^{12}`$ 回です。これが KRR が大きなデータに向かない理由です。

## 2. 多項式カーネルと多項式特徴

**本文の式**:

```math
(x x' + 1)^3 = 1 + 3 x x' + 3 x^2 x'^2 + x^3 x'^3
```

### 展開を確かめる

$`(A + 1)^3 = A^3 + 3A^2 + 3A + 1`$（中学・高校の展開公式）に $`A = x x'`$ を入れると、上の式になります。

### 数字で、2 つの計算が一致することを確かめる

$`x = 1`$、$`x' = 2`$ のとき:

- **カーネルで計算**: $`(1 \times 2 + 1)^3 = 3^3 = 27`$
- **特徴を作って内積**: $`\phi(x) = [1,\ \sqrt{3} x,\ \sqrt{3} x^2,\ x^3]`$ なので、

| | 1 番目 | 2 番目 | 3 番目 | 4 番目 |
|---|---|---|---|---|
| $`\phi(1)`$ | 1 | $`\sqrt{3}`$ | $`\sqrt{3}`$ | 1 |
| $`\phi(2)`$ | 1 | $`2\sqrt{3}`$ | $`4\sqrt{3}`$ | 8 |
| 掛け算 | 1 | 6 | 12 | 8 |

合計 $`1 + 6 + 12 + 8 = 27`$。一致します。$`\sqrt{3}`$ が付いているのは、掛け合わせたときに展開の係数 3 が出るようにするためです。

### なぜ「作らない」ほうが得なのか

カーネルの計算は「掛け算 1 回、足し算 1 回、3 乗 1 回」で済みますが、特徴を作る方法は特徴の数だけ掛け算が要ります。元の特徴が $`p`$ 個、次数 $`d`$ のとき、特徴の数は $`\binom{p + d}{d}`$ 個（[1.1 4/4 数式編](./01_linear_models_4_robust_poly_math.md#poly)）。

| 元の特徴 $`p`$ | 次数 $`d`$ | 作る特徴の数 | カーネルの計算 |
|---|---|---|---|
| 1 | 3 | 4 | 内積（1 回の掛け算）+ 3 乗 |
| 100 | 3 | 176,851 | 内積（100 回の掛け算）+ 3 乗 |

特徴を**作らずに**、内積だけで同じ答えを出す工夫を「**カーネルトリック**」と呼びます。

## 3. RBF カーネル

**本文の式**:

```math
k(x, x') = \exp\left( -\gamma \, \| x - x' \|_2^2 \right)
```

### 距離と $`\gamma`$ を変えて計算する

| 距離 $`\lVert x - x' \rVert`$ | 距離の 2 乗 | $`\gamma = 0.25`$ | $`\gamma = 1`$ | $`\gamma = 4`$ |
|---|---|---|---|---|
| 0 | 0 | 1 | 1 | 1 |
| 0.5 | 0.25 | 0.939 | 0.779 | 0.368 |
| 1 | 1 | 0.779 | 0.368 | 0.018 |
| 2 | 4 | 0.368 | 0.018 | 0.0000001 |

- $`\gamma`$ が**小さい**ほど、遠くの点も「似ている」と数える → 影響範囲が広く、予測はなめらか（やりすぎると、ぼやけて未学習）。
- $`\gamma`$ が**大きい**ほど、すぐ近くの点だけが「似ている」 → 影響範囲が狭く、予測はギザギザ（やりすぎると、学習データの点だけに反応する過学習）。

### $`\gamma`$ と「長さのスケール」$`\ell`$

ガウス過程（1.7 節）などでは、RBF カーネルを $`\exp\left(-\frac{\lVert x - x' \rVert^2}{2 \ell^2}\right)`$ と書きます。見比べると

```math
\gamma = \frac{1}{2 \ell^2}
```

です。$`\ell`$ は「どれくらいの距離まで影響が届くか」の目安で、距離が $`\ell`$ のとき似ている度合いは $`e^{-1/2} \approx 0.61`$ です。$`\ell = 1`$ なら $`\gamma = 0.5`$、$`\ell = 0.1`$ なら $`\gamma = 50`$ です。

### なぜ特徴のスケーリングが大事なのか

距離の 2 乗は、特徴ごとの差の 2 乗の合計です。「年齢（差が 10 くらい）」と「年収（差が 100 万くらい）」をそのまま使うと、距離はほぼ年収だけで決まり、年齢は無視されます。RBF カーネルを使う前に `StandardScaler` で単位をそろえるのは、このためです。

## 4. 2 つの損失関数

**本文の表の式**: 二乗誤差 $`r^2`$、ε-不感損失 $`\max(0,\ \lvert r \rvert - \epsilon)`$（$`r = y - \hat{y}`$）

### 数字で比べる（$`\epsilon = 0.1`$）

| 残差 $`r`$ | 二乗誤差 $`r^2`$ | ε-不感損失 |
|---|---|---|
| 0.05 | 0.0025 | **0**（$`\epsilon`$ 以内なので罰なし） |
| 0.1 | 0.01 | 0（ちょうど境目） |
| 0.3 | 0.09 | 0.2 |
| 2 | **4** | 1.9 |

- 小さなずれ: 二乗誤差は少しでも罰するが、ε-不感損失は**罰 0**。
- 大きなずれ: 二乗誤差は 2 乗で急に大きくなるが、ε-不感損失は**直線**でしか増えない（外れ値に強め）。

### スパース性とのつながり

1 章で見たように、KRR の双対係数は $`a_i = \frac{\text{残差}_i}{\alpha}`$ なので、どのサンプルも 0 以外の係数を持ちます。ε-不感損失では、ずれが $`\epsilon`$ 以内のサンプルは損失に何も寄与しないので、「そのサンプルを少し動かしても答えが変わらない」= 係数が**ちょうど 0** になります。予測に必要なのは、係数が 0 でない点（サポートベクター）だけです。

| | KRR | SVR |
|---|---|---|
| 学習 | 連立方程式を 1 回解く（閉形式） | 繰り返し計算で最適化 |
| 予測に使う学習データ | **全部** | サポートベクターだけ |
| 向いている場面 | 中規模で、学習を速く | 予測を速く、外れ値に少し強く |
