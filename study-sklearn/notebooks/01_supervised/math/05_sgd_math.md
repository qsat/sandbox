## 1. 正則化の強さの換算

**本文の式**:

```math
E(w, b) = \frac{1}{n} \sum_{i=1}^{n} L(y_i, f(x_i)) + \alpha R(w)
```

### 「合計」と「平均」の違いを数字で

サンプル数 $`n = 200`$ とします。

**`LogisticRegression(C=1)` の場合**

```math
C \times (\text{損失の合計}) + \frac{1}{2} \lVert w \rVert^2
```

全体を $`nC = 200`$ で割っても、最小になる $`w`$ は変わりません（全体を同じ数で割っても、いちばん低い場所は同じ）。

```math
\frac{1}{200} (\text{損失の合計}) + \frac{1}{200} \cdot \frac{1}{2} \lVert w \rVert^2 = (\text{損失の平均}) + 0.005 \times \frac{1}{2}\lVert w \rVert^2
```

これは SGD の形で $`\alpha = 0.005 = \frac{1}{nC}`$ です。

**`Ridge(alpha=1)` の場合**

```math
\sum_i (y_i - f(x_i))^2 + 1 \times \lVert w \rVert^2
```

SGD の二乗誤差は $`\frac{1}{2}(y - f)^2`$、正則化は $`\frac{1}{2} \lVert w \rVert^2`$ なので、上の式を $`2n = 400`$ で割ると、

```math
\frac{1}{200} \sum_i \frac{1}{2}(y_i - f(x_i))^2 + \frac{1}{200} \cdot \frac{1}{2} \lVert w \rVert^2
```

で、$`\alpha = \frac{1}{200} = 0.005`$。つまり $`\alpha_\text{Ridge} = n \alpha = 200 \times 0.005 = 1`$ です。

| 専用の推定器 | $`n = 200`$ のときの SGD の `alpha` |
|---|---|
| `LogisticRegression(C=1)` | $`\frac{1}{200 \times 1} = 0.005`$ |
| `LogisticRegression(C=10)` | $`0.0005`$ |
| `Ridge(alpha=1)` | $`\frac{1}{200} = 0.005`$ |

### つまずきやすい点

同じ「正則化の強さ」でも、データが 2 倍になると、SGD の `alpha` を半分にしないと同じ答えになりません。「平均の損失」は件数が増えても大きさが変わらないのに、「合計の損失」は件数に比例して大きくなるからです。

## 2. One-Class SVM の最適化問題

**本文の式**（3 つ目が SGD で解く形）:

```math
\min_{w, \rho} \frac{1}{2} \lVert w \rVert^2 - \rho + \frac{1}{\nu n} \sum_{i=1}^n \max(0, \rho - \langle w, x_i \rangle)
```

```math
\min_{w, b} \frac{\nu}{2} \lVert w \rVert^2 + b \nu + \frac{1}{n} \sum_{i=1}^n \max(0, 1 - (\langle w, x_i \rangle + b))
```

### 2 つ目から 3 つ目への書き換え（中学の式変形）

1. 2 つ目の式全体に $`\nu`$ を掛ける（最小の場所は変わらない）:
   $`\frac{\nu}{2}\lVert w \rVert^2 - \nu\rho + \frac{1}{n}\sum_i \max(0, \rho - \langle w, x_i \rangle)`$
2. $`b = 1 - \rho`$ と置く（$`\rho = 1 - b`$）:
   - $`\rho - \langle w, x_i \rangle = 1 - (\langle w, x_i \rangle + b)`$
   - $`-\nu\rho = -\nu + b\nu`$
3. 定数 $`-\nu`$ は最小の場所に関係ないので捨てる。

これで 3 つ目の式になります。こうすると、SVM（`SGDClassifier` のヒンジ損失）とほぼ同じ形になり、同じ SGD の仕組みで解けます。

### なぜ $`\nu`$ が「外れ値の割合の上限」になるのか

$`n = 10`$ 件、$`\nu = 0.2`$ とします。1 点あたりの罰の重みは $`\frac{1}{\nu n} = \frac{1}{2} = 0.5`$ です。

しきい値 $`\rho`$ を少し（$`\delta`$ だけ）上げると:

- $`-\rho`$ の項で、目的関数は $`\delta`$ だけ**下がる**（得）
- $`\rho`$ より下にある点（はみ出している点）1 個につき、罰が $`0.5 \times \delta`$ だけ**上がる**（損）

はみ出している点が 2 個未満なら、上げたほうが得です。2 個を超えると損になります。だから、はみ出す点が**ちょうど $`\nu n = 2`$ 個くらい**のところで止まります。これは [1.1 4/4 数式編のピンボール損失](./01_linear_models_4_robust_poly_math.md#pinball)と同じ「釣り合い」の考え方です。

## 3. SGD の計算量

**本文の式**: $`O(k n \bar{p})`$

### 数字で見積もる

| 状況 | $`k`$（エポック） | $`n`$（件数） | $`\bar{p}`$（0 でない特徴） | 計算回数 |
|---|---|---|---|---|
| 文書分類（疎） | 5 | 100 万 | 100 | $`5 \times 10^8`$ |
| 同じデータを密に扱う | 5 | 100 万 | 10 万 | $`5 \times 10^{11}`$ |

1 秒に $`10^9`$ 回計算できるとすると、疎なら 0.5 秒、密なら 500 秒（8 分以上）です。疎な行列のまま渡すことが大事な理由です。

### 他の解き方との比較

最小二乗法を正規方程式で解くと、およそ $`n p^2`$ 回の計算が要ります（$`p \times p`$ の表を作るため）。$`p = 10`$ 万なら $`p^2 = 10^{10}`$ で、$`n = 100`$ 万件だと $`10^{16}`$ 回。SGD は $`p`$ について**1 乗**なので、特徴が多いほど有利です。

### 「データが増えても時間が増えない」の意味

SGD の誤差は、更新回数 $`t`$ についておよそ $`\frac{1}{t}`$ の速さで減ります。目標の精度に必要な更新回数は、データの件数ではなく**精度で決まる**ので、データが十分多ければ 1 周する前に必要な精度に届きます。

## 4. SGD が最小化するもの

**本文の式**:

```math
E(w, b) = \frac{1}{n} \sum_{i=1}^{n} L(y_i, f(x_i)) + \alpha R(w)
```

### 小さなデータで $`E`$ を計算する

データ $`(x, y) = (1, 1), (2, 2), (3, 2)`$、二乗誤差 $`L = \frac{1}{2}(y - f)^2`$、L2 正則化 $`R = \frac{1}{2} w^2`$、$`\alpha = 0.1`$、そして $`w = 0.8`$、$`b = 0`$ のとき:

| $`x`$ | $`y`$ | 予測 $`f = 0.8x`$ | 残差 | 損失 $`\frac{1}{2}(\text{残差})^2`$ |
|---|---|---|---|---|
| 1 | 1 | 0.8 | 0.2 | 0.02 |
| 2 | 2 | 1.6 | 0.4 | 0.08 |
| 3 | 2 | 2.4 | −0.4 | 0.08 |

- 損失の平均: $`(0.02 + 0.08 + 0.08) / 3 = 0.06`$
- 正則化: $`0.1 \times \frac{1}{2} \times 0.8^2 = 0.032`$
- $`E = 0.06 + 0.032 = 0.092`$

SGD は、この $`E`$ を少しずつ小さくするように $`w`$ と $`b`$ を動かします。

### 「損失 + 正則化」の組み合わせで、別のモデルになる

| `loss` | `penalty` | できあがるモデル |
|---|---|---|
| `"hinge"` | `"l2"` | 線形 SVM（`LinearSVC` と同じ問題） |
| `"log_loss"` | `"l2"` | ロジスティック回帰 |
| `"squared_error"` | `"l2"` | Ridge |
| `"squared_error"` | `"l1"` | Lasso |

SGD は「解き方」で、何を解くか（モデル）は `loss` と `penalty` で決まります。

## 5. 損失関数の式

### 分類の損失を数字で並べる

$`m = y_i f(x_i)`$（正しい側への深さ）を変えて計算します。

| $`m`$ | 0-1 損失 | ヒンジ | パーセプトロン | 対数損失 | 二乗ヒンジ | 修正 Huber |
|---|---|---|---|---|---|---|
| 2 | 0 | 0 | 0 | 0.127 | 0 | 0 |
| 1 | 0 | 0 | 0 | 0.313 | 0 | 0 |
| 0.5 | 0 | 0.5 | 0 | 0.474 | 0.25 | 0.25 |
| 0 | 1 | 1 | 0 | 0.693 | 1 | 1 |
| −1 | 1 | 2 | 1 | 1.313 | 4 | 4 |
| −3 | 1 | 4 | 3 | 3.049 | 16 | **12** |

- **ヒンジ・二乗ヒンジ・修正 Huber**: $`m \ge 1`$（十分正しい）なら 0。$`m < 1`$ でも罰があるので、「ぎりぎり正解」も嫌う。
- **パーセプトロン**: 正解なら（$`m > 0`$）罰 0。マージンの考え方がない。
- **対数損失**: どこでも 0 にはならない（確率を出すため、「もっと自信を持て」と言い続ける）。
- **修正 Huber**: $`m = -3`$ で二乗ヒンジは 16 ですが、修正 Huber は直線 $`-4m = 12`$ に切り替わり、大きく外れた点の影響を抑えます。

### 修正 Huber のつなぎ目

$`m = -1`$ で、二乗の式 $`(1 - m)^2 = 4`$ と直線の式 $`-4m = 4`$ が等しく、傾きもどちらも $`-4`$ でそろっています（[1.1 4/4 数式編の Huber 損失](./01_linear_models_4_robust_poly_math.md#huber)と同じ工夫）。

### 回帰の損失を数字で並べる（Huber の $`\varepsilon = 1`$、ε-不感の $`\varepsilon = 0.1`$）

| 残差 $`r`$ | 二乗誤差 $`\frac{1}{2}r^2`$ | Huber | ε-不感 |
|---|---|---|---|
| 0.05 | 0.00125 | 0.00125 | 0 |
| 0.5 | 0.125 | 0.125 | 0.4 |
| 2 | 2 | $`1 \times 2 - 0.5 = 1.5`$ | 1.9 |
| 10 | **50** | 9.5 | 9.9 |

外れ値（残差 10）に対して、二乗誤差だけが極端に大きくなります。

## 6. 正則化の項

### 同じ係数で 3 つの正則化を計算する

$`w = (0.6, -0.8)`$ のとき:

| 正則化 | 計算 | 値 |
|---|---|---|
| L2 | $`\frac{1}{2}(0.36 + 0.64)`$ | 0.5 |
| L1 | $`0.6 + 0.8`$ | 1.4 |
| Elastic Net（`l1_ratio=0.15` → $`\rho = 0.85`$） | $`0.85 \times 0.5 + 0.15 \times 1.4`$ | 0.635 |

### なぜ L1 だと係数がちょうど 0 になるのか（更新の 1 歩で見る）

係数 $`w = 0.05`$、学習率 $`\eta = 0.1`$、$`\alpha = 1`$ で、正則化だけの 1 歩を比べます。

- **L2**: 傾きは $`w`$ そのもの。$`0.05 - 0.1 \times 0.05 = 0.045`$。**同じ割合**で縮むので、0 に近づくほど縮み方も小さくなり、ちょうど 0 にはなりません。
- **L1**: 傾きは $`w`$ の符号（$`+1`$）。$`0.05 - 0.1 \times 1 = -0.05`$。**一定の量**で引っ張るので、0 を通り越します。scikit-learn は、0 を通り越したら 0 で止める（切り詰める）ので、係数は**ちょうど 0** になります。

| 歩数 | L2 の $`w`$ | L1 の $`w`$（0 で止める） |
|---|---|---|
| 0 | 0.05 | 0.05 |
| 1 | 0.045 | **0** |
| 10 | 0.017 | 0 |

### 等高線の形

$`R(w) = 1`$ になる点を描くと、L2 は円、L1 はひし形（角が軸の上）、Elastic Net はその中間の「角の丸いひし形」になります。損失の等高線が最初にぶつかる場所が、ひし形では角（どれかの係数が 0）になりやすい、というのが図で見る説明です（[1.1 1/4 数式編の Lasso](./01_linear_models_1_ols_regularization_math.md#lasso)）。

## 7. 更新式

**本文の式**:

```math
w \leftarrow w - \eta \left[ \alpha \frac{\partial R(w)}{\partial w} + \frac{\partial L(w^T x_i + b, y_i)}{\partial w} \right]
```

### 1 歩を手で計算する（二乗誤差 + L2）

今の値 $`w = 0`$、$`b = 0`$、学習率 $`\eta = 0.1`$、$`\alpha = 0.01`$。サンプル $`x = 2`$、$`y = 3`$ を 1 件使います。

1. 予測: $`f = 0 \times 2 + 0 = 0`$、残差 $`y - f = 3`$
2. 損失 $`\frac{1}{2}(y - f)^2`$ の $`w`$ についての傾き: $`-(y - f) \times x = -3 \times 2 = -6`$
3. 正則化 $`\frac{1}{2}w^2`$ の傾き: $`w = 0`$
4. 更新: $`w \leftarrow 0 - 0.1 \times (0.01 \times 0 + (-6)) = 0.6`$
5. 切片（正則化なし）: 傾き $`-(y - f) = -3`$ なので、$`b \leftarrow 0 - 0.1 \times (-3) = 0.3`$

新しい予測は $`0.6 \times 2 + 0.3 = 1.5`$ で、正解 3 に半分近づきました。

### 傾き（偏微分）$`\frac{\partial L}{\partial w}`$ の意味

「$`w`$ を少しだけ増やしたとき、損失がどれだけ増えるか」の比率です。上の例で傾きが $`-6`$ なのは、「$`w`$ を 0.01 増やすと損失が約 0.06 **減る**」ということ。だから傾きの**逆向き**（マイナスを付けた方向）に進みます。

### ヒンジ損失の 1 歩

ヒンジ損失 $`\max(0, 1 - y f)`$ の傾きは、

- $`y f < 1`$（マージンの中・誤分類）なら $`-y x`$
- $`y f \ge 1`$ なら 0（**何もしない**。正則化の分だけ縮む）

です。$`y = +1`$、$`x = 2`$、$`w = 0.1`$、$`b = 0`$ なら $`y f = 0.2 < 1`$ なので、$`w \leftarrow 0.1 - 0.1 \times (0.01 \times 0.1 - 2) = 0.2999`$。正しい側にしっかり入った点からは学ばない、というのが SVM らしさです。

## 8. 学習率のスケジュール

### 数字で歩幅の変化を見る

**`"invscaling"`**（$`\eta_0 = 0.01`$、`power_t=0.25`）: $`\eta^{(t)} = \frac{0.01}{t^{0.25}}`$

| $`t`$ | 1 | 16 | 10,000 |
|---|---|---|---|
| $`\eta`$ | 0.01 | 0.005 | 0.001 |

$`t^{0.25}`$ は「4 乗根」で、$`16^{0.25} = 2`$、$`10000^{0.25} = 10`$ です。ゆっくり小さくなります。

**`"optimal"`**（例として $`\alpha = 0.01`$、$`t_0 = 100`$）: $`\eta^{(t)} = \frac{1}{0.01 \times (100 + t)}`$

| $`t`$ | 0 | 100 | 900 |
|---|---|---|---|
| $`\eta`$ | 1 | 0.5 | 0.1 |

### なぜ $`\frac{1}{t}`$ のように減らすとよいのか

学習率の減らし方には、2 つの条件が知られています。

1. 歩幅の**合計**は、いくらでも大きくなる → どんなに遠くの谷底にも、いつかは届く
2. 歩幅の **2 乗の合計**は、ある値で止まる → ノイズによるふらつきの合計が有限になり、最後は止まる

$`\frac{1}{t}`$ はちょうどこれを満たします。

| | 1 万項まで足すと | 項を増やし続けると |
|---|---|---|
| $`1 + \frac{1}{2} + \frac{1}{3} + \cdots`$ | 9.79 | いくらでも大きくなる |
| $`1 + \frac{1}{4} + \frac{1}{9} + \cdots`$ | 1.645 | 約 1.645 で止まる |

一定の学習率（`"constant"`）だと条件 2 を満たさないので、谷底のまわりでうろうろし続けます（本文の 1 章の図）。

## 9. 平均化 SGD

**本文の式**:

```math
\texttt{coef\_} = \frac{1}{T} \sum_{t=0}^{T-1} w^{(t)}
```

### 数字で平均をとる

谷底（正解）が $`w = 1`$ のまわりで、SGD の重みが $`1.2, 0.8, 1.1, 0.9`$ とふらついたとします。最後の値は 0.9（ずれ 0.1）ですが、平均は $`(1.2 + 0.8 + 1.1 + 0.9) / 4 = 1.0`$ で、ふらつきが打ち消し合って正解に近づきます。

### 全部覚えておかなくても計算できる（逐次平均）

平均は、毎回の更新で

```math
\bar{w}^{(t)} = \bar{w}^{(t-1)} + \frac{w^{(t)} - \bar{w}^{(t-1)}}{t}
```

と、「今の平均」を少しだけ動かすことで計算できます。

| $`t`$ | $`w^{(t)}`$ | 計算 | 平均 $`\bar{w}^{(t)}`$ |
|---|---|---|---|
| 1 | 1.2 | — | 1.2 |
| 2 | 0.8 | $`1.2 + (0.8 - 1.2)/2`$ | 1.0 |
| 3 | 1.1 | $`1.0 + (1.1 - 1.0)/3`$ | 1.033 |
| 4 | 0.9 | $`1.033 + (0.9 - 1.033)/4`$ | 1.0 |

過去の重みを全部保存しなくてよいので、メモリが増えません。

### `average=10` の意味

最初のうちの重みは谷底から遠いので、平均に入れると足を引っ張ります。`average=10` のように整数を指定すると、10 件見た後から平均をとり始めます。
