## 1. 正則化の強さの換算

### 🔢 数式を読む: 正則化の強さの換算

SGD が最小化するのは（8 章）、

```math
E(w, b) = \frac{1}{n} \sum_{i=1}^{n} L(y_i, f(x_i)) + \alpha R(w)
```

です。損失の**平均**に $`\alpha R(w)`$ を足しています。一方、

- `LogisticRegression` は「$`C \times`$ 損失の**合計** $`+ \frac{1}{2}\lVert w \rVert^2`$」を最小化します。全体を $`nC`$ で割ると SGD の形になるので、**$`\alpha = \frac{1}{nC}`$** です。
- `Ridge` は「二乗誤差の**合計** $`+ \alpha_\text{Ridge} \lVert w \rVert^2`$」を最小化します。SGD の二乗誤差は $`\frac{1}{2}(y - f)^2`$、正則化は $`\frac{1}{2}\lVert w \rVert^2`$ なので、全体を $`2n`$ 倍すると比べられて、**$`\alpha_\text{Ridge} = n \, \alpha`$** です。

**日本語で読むと**: SGD の `alpha` は「1 件あたりの平均の損失」に対する正則化の強さなので、合計で書く推定器と比べるときはサンプル数 $`n`$ を掛け直す必要がある。

## 2. One-Class SVM の最適化問題

### 📖 数式の詳細（Mathematical details）

実装は確率的勾配降下法の実装に基づいています。One-Class SVM の元の最適化問題は次のとおりです。

```math
\begin{aligned}
\min_{w, \rho, \xi} \quad & \frac{1}{2} \lVert w \rVert^2 - \rho + \frac{1}{\nu n} \sum_{i=1}^n \xi_i \\
\text{s.t.} \quad & \langle w, x_i \rangle \geq \rho - \xi_i, \quad 1 \leq i \leq n \\
& \xi_i \geq 0, \quad 1 \leq i \leq n
\end{aligned}
```

ここで $`\nu \in (0, 1]`$ は、外れ値の割合とサポートベクターの割合を制御する、利用者が指定するパラメータです。スラック変数 $`\xi_i`$ を消すと、この問題は次と同等になります。

```math
\min_{w, \rho} \frac{1}{2} \lVert w \rVert^2 - \rho + \frac{1}{\nu n} \sum_{i=1}^n \max(0, \rho - \langle w, x_i \rangle)
```

定数 $`\nu`$ を掛けて、切片 $`b = 1 - \rho`$ を導入すると、次の同等な最適化問題が得られます。

```math
\min_{w, b} \frac{\nu}{2} \lVert w \rVert^2 + b \nu + \frac{1}{n} \sum_{i=1}^n \max(0, 1 - (\langle w, x_i \rangle + b))
```

これは 8 章の数式の問題で、$`y_i = 1`$（$`1 \le i \le n`$）、$`\alpha = \nu`$、$`L`$ をヒンジ損失、$`R`$ を L2 ノルムとしたものとよく似ています。最適化のループに、項 $`b \nu`$ を加えるだけで済みます。`SGDClassifier` や `SGDRegressor` と同じく、`SGDOneClassSVM` も `average=True` で平均化 SGD を使えます。

### 🔢 数式を読む

| 記号 | 意味 |
|---|---|
| $`\langle w, x_i \rangle`$ | サンプル $`x_i`$ の「正常らしさ」のスコア（内積） |
| $`\rho`$ | しきい値。スコアが $`\rho`$ 以上なら正常 |
| $`\xi_i`$ | スコアが $`\rho`$ に足りない分（はみ出し） |
| $`\frac{1}{2}\lVert w \rVert^2 - \rho`$ | 「$`w`$ を小さく保ちつつ、しきい値 $`\rho`$ をできるだけ高く」＝ 正常なデータを原点からできるだけ遠くに分離する |
| $`\frac{1}{\nu n} \sum \xi_i`$ | はみ出しの罰。$`\nu`$ が小さいほど重い（はみ出す点を少なくする） |

**日本語で読むと**: 正常なデータのほとんどが「スコア ≥ しきい値」になるような、なるべく単純な $`w`$ と高いしきい値を探す。はみ出してよい割合の目安が $`\nu`$。式を変形すると、「全サンプルの正解が +1 のヒンジ損失の分類」とほぼ同じ形になるので、`SGDClassifier` と同じ仕組みで解ける。

## 3. SGD の計算量

### 🔢 数式を読む

| 記号 | 意味 |
|---|---|
| $`k`$ | エポック数（データ全体を何周するか） |
| $`n`$ | サンプル数 |
| $`\bar{p}`$ | 1 サンプルあたりの 0 でない特徴の数の平均（密なデータなら $`p`$ そのもの） |

**日本語で読むと**: 1 件の更新には、その件の 0 でない特徴の数だけ計算が要る。それを $`n`$ 件、$`k`$ 周するので、合計は $`k \times n \times \bar{p}`$。文書データのように、特徴が数十万あっても 1 文書に出る単語は数百なら、$`\bar{p}`$ は数百で済む。

## 4. SGD が最小化するもの

学習データの集合 $`\{(x_1, y_1), \ldots, (x_n, y_n)\}`$（$`x_i \in \mathbf{R}^m`$、$`y_i \in \mathbf{R}`$。分類なら $`y_i \in \{-1, 1\}`$）が与えられたとき、目標は、モデルのパラメータ $`w \in \mathbf{R}^m`$ と切片 $`b \in \mathbf{R}`$ を持つ**線形のスコア関数** $`f(x) = w^T x + b`$ を学習することです。2 値分類の予測では、$`f(x)`$ の符号を見るだけです。モデルのパラメータを見つけるために、次の**正則化付きの学習誤差**を最小化します。

```math
E(w, b) = \frac{1}{n} \sum_{i=1}^{n} L(y_i, f(x_i)) + \alpha R(w)
```

$`L`$ はモデルの当てはまりの悪さを測る**損失関数**、$`R`$ はモデルの複雑さを罰する**正則化の項**（ペナルティ）で、$`\alpha > 0`$ は正則化の強さを決める非負のハイパーパラメータです。

### 🔢 数式を読む

| 記号 | 意味 | scikit-learn |
|---|---|---|
| $`f(x) = w^T x + b`$ | 線形のスコア（予測） | `decision_function` / `predict` |
| $`L(y_i, f(x_i))`$ | 1 件の損失 | `loss` |
| $`\frac{1}{n} \sum_i`$ | 全サンプルの**平均** | — |
| $`R(w)`$ | 正則化の項 | `penalty` |
| $`\alpha`$ | 正則化の強さ | `alpha`（既定 0.0001） |

**日本語で読むと**: 「1 件あたりの平均の損失」と「係数の複雑さ × $`\alpha`$」の合計を最小にする。どの損失・どの正則化を選ぶかで、ロジスティック回帰にも SVM にも Ridge にもなる。

## 5. 損失関数の式

| 名前 | $`L(y_i, f(x_i))`$ | 同等のモデル |
|---|---|---|
| ヒンジ（ソフトマージン） | $`\max(0, 1 - y_i f(x_i))`$ | サポートベクター分類 |
| パーセプトロン | $`\max(0, -y_i f(x_i))`$ | パーセプトロン |
| 修正 Huber | $`y_i f(x_i) > -1`$ なら $`\max(0, 1 - y_i f(x_i))^2`$、それ以外は $`-4 y_i f(x_i)`$ | — |
| 対数損失 | $`\log(1 + \exp(-y_i f(x_i)))`$ | ロジスティック回帰 |
| 二乗誤差 | $`\frac{1}{2}(y_i - f(x_i))^2`$ | 線形回帰（$`R`$ によって Ridge や Lasso） |
| Huber | $`\lvert y_i - f(x_i) \rvert \le \varepsilon`$ なら二乗誤差と同じ、それ以外は $`\varepsilon \lvert y_i - f(x_i) \rvert - \frac{1}{2}\varepsilon^2`$ | 頑健な回帰 |
| ε-不感 | $`\max(0, \lvert y_i - f(x_i) \rvert - \varepsilon)`$ | サポートベクター回帰 |

**本文の図の補足**: パーセプトロン損失は $`\max(0, -y f(x))`$ なので、$`-1 < y f(x) \le 0`$ では 0-1 損失を下回ります。対数損失は自然対数 $`\log(1 + e^{-y f(x)})`$ なので、$`y f(x) = 0`$ での値は $`\log 2 \approx 0.69`$ です（底を 2 にした $`\log_2`$ なら、ちょうど 0-1 損失を上から抑えます）。修正 Huber は $`y f(x) < -1`$ で直線 $`-4 y f(x)`$ に切り替わります。

## 6. 正則化の項

| 正則化 | $`R(w)`$ | 性質 |
|---|---|---|
| L2 ノルム | $`R(w) := \frac{1}{2} \sum_{j=1}^{m} w_j^2 = \frac{1}{2} \lVert w \rVert_2^2`$ | — |
| L1 ノルム | $`R(w) := \sum_{j=1}^{m} \lvert w_j \rvert`$ | 疎な解になる |
| Elastic Net | $`R(w) := \frac{\rho}{2} \sum_{j=1}^{m} w_j^2 + (1 - \rho) \sum_{j=1}^{m} \lvert w_j \rvert`$ | L2 と L1 の凸結合。$`\rho`$ は `1 - l1_ratio` |

> ⚠️ **記号の注意**: ガイドの Elastic Net の式では $`\rho = 1 -`$ `l1_ratio` で、**$`\rho`$ は L2 の割合**です。1.1 の 1/4 の `ElasticNet` の式では、$`\rho`$ は `l1_ratio`（**L1 の割合**）でした。同じ記号 $`\rho`$ が逆の意味で使われているので注意してください（ガイドの原文には、Elastic Net の L2 の和の上限が $`n`$ と書かれていますが、$`m`$ の誤記と思われます）。

## 7. 更新式

`SGDClassifier` は、1 次の SGD の学習ルーチンを実装しています。アルゴリズムは学習データを順に見ていき、データごとに、次の更新規則でモデルのパラメータを更新します。

```math
w \leftarrow w - \eta \left[ \alpha \frac{\partial R(w)}{\partial w} + \frac{\partial L(w^T x_i + b, y_i)}{\partial w} \right]
```

$`\eta`$ は、パラメータ空間での歩幅を決める**学習率**です。切片 $`b`$ も同じように更新されますが、正則化はかけません（疎な行列の場合は、9 章で説明する追加の減衰があります）。

### 🔢 数式を読む: 更新式

| 記号 | 意味 |
|---|---|
| $`w \leftarrow \dots`$ | 右辺の値で $`w`$ を上書きする（プログラムの代入 `w = ...` と同じ） |
| $`\eta`$ | 学習率（1 歩の大きさ） |
| $`\frac{\partial R(w)}{\partial w}`$ | 正則化の項の勾配。L2 なら $`w`$ そのもの（「係数を 0 の方へ引き戻す力」） |
| $`\frac{\partial L(w^T x_i + b, y_i)}{\partial w}`$ | この 1 件の損失の勾配。二乗誤差なら $`(f(x_i) - y_i) \, x_i`$（「予測のずれ × 入力」） |

**日本語で読むと**: 1 件見るたびに、「この 1 件の損失を減らす向き」と「係数を小さくする向き」を合わせた方向へ、学習率 $`\eta`$ の分だけ係数を動かす。

> 📚 **用語**: **1 次の手法（first-order）** — 1 階微分（勾配）だけを使う最適化の手法。2 階微分（ヘッセ行列）を使うニュートン法は 2 次の手法。

**9 章の「スカラーとベクトルの積」の工夫**: L2 正則化の更新は $`w \leftarrow (1 - \eta \alpha) w - \eta \nabla L`$ と書けます。$`w = s \cdot v`$（スカラー $`s`$ とベクトル $`v`$）と分けて持てば、$`(1 - \eta \alpha)`$ を掛ける処理は $`s`$ だけを更新すれば済み、$`\nabla L`$ の部分は 0 でない特徴の分だけ $`v`$ を更新すれば済みます。

## 8. 学習率のスケジュール

| `learning_rate` | 式 | 既定で使うクラス |
|---|---|---|
| `"optimal"` | $`\eta^{(t)} = \frac{1}{\alpha (t_0 + t)}`$ | `SGDClassifier` |
| `"invscaling"` | $`\eta^{(t)} = \frac{\eta_0}{t^{power\_t}}`$ | `SGDRegressor` |
| `"constant"` | $`\eta = \eta_0`$（`eta0`） | — |
| `"adaptive"` | $`\eta_0`$ から始め、停止の基準に達するたびに 5 で割る。1e-6 を下回ったら止まる | — |

- `"optimal"`: $`t`$ は時間のステップ（合計で `n_samples * n_iter` ステップ）。$`t_0`$ は、**ボトゥ**が提案した経験則で決めます。初期の更新の大きさが、重みの大きさの期待値と同程度になるようにするものです（学習データのノルムがおよそ 1 であることを前提にしている）。正確な定義は `BaseSGD` の `_init_t` にあります。
- `"invscaling"`: $`\eta_0`$ と $`power\_t`$ は、利用者が `eta0` と `power_t` で指定するハイパーパラメータです。

## 9. 平均化 SGD

```math
\texttt{coef\_} = \frac{1}{T} \sum_{t=0}^{T-1} w^{(t)}
```

$`T`$ は更新の合計回数で、`t_` 属性で分かります。
