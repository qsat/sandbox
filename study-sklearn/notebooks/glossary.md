# 用語集

この教材で何度も出てくる用語を、数式を使わずにまとめました。各ノートでは初めて出てきたときに説明していますが、後のノートでは説明を省いていることがあります。忘れたらここに戻ってきてください。

「詳しく」の列は、その用語をくわしく扱っているノートです。

## データとモデルの基本

| 用語 | ひとことで | たとえ | 詳しく |
|---|---|---|---|
| **特徴量（特徴）** | 予測の手がかりにする入力の値。コードでは `X` の各列 | 家賃の予測なら「面積」「駅徒歩」 | [1.1（1/4）](./01_supervised/01_linear_models_1_ols_regularization.ipynb) |
| **目的変数** | 予測したい値。コードでは `y` | 家賃 | 同上 |
| **サンプル** | データの 1 件。`X` の 1 行 | 1 つの物件 | 同上 |
| **回帰 / 分類** | 数値を予測する / クラス（種類）を予測する | 家賃を当てる / 花の品種を当てる | 同上、[1.1（3/4）](./01_supervised/01_linear_models_3_classification_glm.ipynb) |
| **モデル / 推定器（Estimator）** | データから学習して予測する仕組み。scikit-learn のクラス | 「経験から見積もる職人」 | 同上 |
| **学習（`fit`）/ 予測（`predict`）** | データから係数などを決める / 決めた係数で新しいデータに答える | 過去問で練習する / 本番の試験を解く | 同上 |
| **係数（`coef_`）/ 切片（`intercept_`）** | 特徴 1 単位あたりの効き目 / すべての特徴が 0 のときの値 | 面積の単価 / 基本料金 | 同上 |
| **ハイパーパラメータ** | 学習の前に人が決める設定値（`alpha`, `C`, `n_neighbors` など） | 料理の「火加減」 | 同上 |
| **教師あり / 教師なし** | 正解（ラベル）を使って学習する / 使わない | 答え付きの問題集 / 答えのない問題集 | [1.2](./01_supervised/02_lda_qda.ipynb) |

## 学習のよしあし

| 用語 | ひとことで | たとえ | 詳しく |
|---|---|---|---|
| **損失（損失関数）** | 予測がどれだけ外れたかを測る物差し。学習はこれを小さくする | 答案の減点の付け方 | [1.5](./01_supervised/05_sgd.ipynb) |
| **過学習（オーバーフィット）** | 学習データには合うのに、新しいデータに通用しない状態 | 過去問の答えを丸暗記した | [1.1（4/4）](./01_supervised/01_linear_models_4_robust_poly.ipynb) |
| **未学習（アンダーフィット）** | 学習データにも合っていない状態。モデルが単純すぎる | 公式を 1 つしか知らない | 同上 |
| **汎化（汎化性能）** | 学習に使っていない新しいデータでの性能 | 初見の問題を解く力 | 同上 |
| **交差検証** | データを分けて、学習に使わなかった部分で成績を測ることを繰り返す方法 | 模試を何回か受けて平均を見る | [1.1（1/4）](./01_supervised/01_linear_models_1_ols_regularization.ipynb) |
| **グリッドサーチ** | ハイパーパラメータの候補を全部試し、交差検証で一番よいものを選ぶ | 火加減と時間の組み合わせを全部試す | [1.3](./01_supervised/03_kernel_ridge.ipynb) |
| **バイアスとバリアンス** | 仮定が単純すぎることによるずれ / データの偶然に振り回されるぶれ | いつも同じ方向に外れる / 毎回ばらばらに外れる | [1.2](./01_supervised/02_lda_qda.ipynb) |
| **ベースライン** | 比較の基準にする単純なモデル | 「まずはこれより良くないと意味がない」線 | [1.1（1/4）](./01_supervised/01_linear_models_1_ols_regularization.ipynb) |
| **R²（決定係数）** | 回帰の当てはまりの指標。1 なら完璧、0 なら平均を答えるのと同じ | — | [1.3](./01_supervised/03_kernel_ridge.ipynb) |
| **正解率 / 再現率** | 全体のうち当たった割合 / 本当にそのクラスのもののうち見つけられた割合 | テストの点 / 見逃しの少なさ | [1.4（1/2）](./01_supervised/04_svm_1_classification_regression.ipynb) |

## 学習の工夫

| 用語 | ひとことで | たとえ | 詳しく |
|---|---|---|---|
| **正則化** | 係数が大きくなりすぎないよう罰を足すこと。過学習を防ぐ | 係数への「税金」 | [1.1（1/4）](./01_supervised/01_linear_models_1_ols_regularization.ipynb) |
| **L1 / L2 正則化** | 係数の絶対値の合計 / 2 乗の合計に罰をかける。L1 は係数をちょうど 0 にしやすい | 不要な人を外す / 全員を少しずつ減給 | 同上 |
| **スパース（疎）** | ほとんどが 0 で、0 でないものが少ない状態 | まばら | 同上 |
| **標準化（スケーリング）** | 特徴ごとに平均を引き、ばらつきで割って、大きさをそろえる | cm と kg を同じ物差しにする | [1.6（1/2）](./01_supervised/06_neighbors_1_knn.ipynb) |
| **パイプライン（`Pipeline`）** | 前処理とモデルを 1 つにつないだもの。前処理の「ずる」を防げる | 工場の流れ作業 | [1.4（2/2）](./01_supervised/04_svm_2_practice_math.ipynb) |
| **ソルバ** | 最小化の問題を実際に解く計算方法 | 同じ目的地への別の道順 | [1.1（3/4）](./01_supervised/01_linear_models_3_classification_glm.ipynb) |
| **勾配降下法 / SGD** | 傾きの逆向きに少しずつ進んで谷底（損失の最小）を探す / 1 件ずつ見て進む版 | 霧の中で足元の傾きだけを頼りに山を下る | [1.5](./01_supervised/05_sgd.ipynb) |
| **カーネル** | 2 つのデータが「どれだけ似ているか」を返す関数 | 似ている度合いの物差し | [1.3](./01_supervised/03_kernel_ridge.ipynb) |

## 分類の言葉

| 用語 | ひとことで | たとえ | 詳しく |
|---|---|---|---|
| **決定境界** | 「ここからこちらはクラス A」と判定が切り替わる境目 | 陣地の境界線 | [1.2](./01_supervised/02_lda_qda.ipynb) |
| **線形 / 非線形** | 境界が直線（平面）/ 曲線 | 定規で引ける / 定規では引けない | 同上 |
| **スコア（`decision_function`）/ 確率（`predict_proba`）** | どちらのクラスにどれだけ寄っているかの点数 / 0〜1 の確率 | 偏差値 / 合格率 | [1.4（1/2）](./01_supervised/04_svm_1_classification_regression.ipynb) |
| **較正** | 「0.8 と言ったら本当に 8 割当たる」ように確率を合わせ直すこと | 天気予報の降水確率を実績に合わせる | 同上 |
| **不均衡なデータ** | クラスごとの件数に大きな差があるデータ | 不正取引は全体の 0.1% | 同上 |
| **one-vs-rest / one-vs-one** | クラスごとに「それか、それ以外か」/ 2 クラスの組ごとに分類器を作る | 個別面接 / 総当たり戦 | 同上 |

## データの形

| 用語 | ひとことで | たとえ | 詳しく |
|---|---|---|---|
| **次元** | 特徴の数 | 物件を表す項目の数 | [1.6（1/2）](./01_supervised/06_neighbors_1_knn.ipynb) |
| **次元の呪い** | 次元が増えると空間が広くなりすぎて、「近い・遠い」の区別がつきにくくなる現象 | 項目が多すぎて、どの物件も「似ていない」 | 同上 |
| **外れ値** | ほかのデータの傾向から大きく外れた点 | 入力ミスの家賃 | [1.1（4/4）](./01_supervised/01_linear_models_4_robust_poly.ipynb) |
| **疎な行列** | ほとんどが 0 の表を、0 以外の値だけで保存する形式 | 単語の出現回数の表 | [1.5](./01_supervised/05_sgd.ipynb) |
